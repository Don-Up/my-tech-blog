How to avoid unnecessary rendering

Foreword

in React development, component rendering efficiency directly affects application performance and user experience. Unnecessary rendering not only wastes computing resources, but also may cause interface stun and reduce response speed. Therefore, reasonably controlling and avoiding unnecessary rendering is an important part of optimizing the performance of React applications.

This article will start with the rendering mechanism, discuss in detail the causes of unnecessary rendering, analyze common problems, and explain how to effectively avoid unnecessary rendering and improve the performance of React applications with specific technical means.

Basic Mechanism of React Rendering and Rendering Trigger Conditions

the rendering of the React component is driven by changes in state or properties (props). React triggers the re-rendering process whenever the state or props of a component changes. The rendering process includes the execution of a function component or a class component. render method call to generate a new virtual DOM, then compare it with the old Virtual DOM (Diff algorithm), and finally update the real DOM.

Unnecessary rendering usually occurs when the state/props of the component itself does not actually change, or even if the change does not affect the content displayed by the component, it still triggers re-rendering.

common scenes that lead to unnecessary rendering

  1. parent component update causes all child components to re-render
    when the parent component state changes, all child components are re-rendered by default, even if the child component props does not change.
  2. The function component creates a new function every time it renders, and passing it to the subcomponent causes the subcomponent to render repeatedly.
    Because the function reference changes, the child component sees the props change.

  1. Lack of proper memo optimization
    for display-only components, not used React.memo or PureComponent you cannot avoid repeated rendering.

How to Avoid Unnecessary Rendering

1. Use React.memo to optimize the function component.

React.memo it is a high-order component. You can compare function components with shallow props to avoid re-rendering when props does not change.

2. Use PureComponent to optimize class components

for class components, you can inherit React.PureComponent , automatically realize shallow comparison optimization.

3. Cache function references to avoid creating new functions every time you render.

Use useCallbackCache functions to avoid re-rendering of subcomponents due to reference changes when the function is passed as props.

4. Cache objects and arrays to avoid reference changes.

Use useMemo cache complex objects or arrays to ensure reference stability.

5. Appropriate split components to reduce the rendering range

by reasonably splitting the component, the entire large component is prevented from being re-rendered due to partial state changes.

6. Control status granularity to avoid unnecessary status updates

avoid putting multiple unrelated data into the same state, split the state, and reduce the scope of triggering rendering.

7. Use key identify list components correctly to avoid repeated rendering and remounting

Summary

avoiding unnecessary rendering is the core means to optimize React performance. The key is to understand the React rendering mechanism, manage state and props reasonably, and use React.memo , PureComponent , useCallback and useMemo and other optimization tools to ensure the stability of props passed to subcomponents and avoid reference changes. In addition, component splitting and state granularity control are also important strategies. The comprehensive application of these methods can effectively reduce the repeated rendering and improve the application response speed and user experience.
