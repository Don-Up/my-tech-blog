What are the functions of Portals and in what scenarios are they used

Foreword

in React application development, the rendering structure of components is generally managed strictly according to the nested DOM tree at the parent-child level. However, in the actual UI design, there are cases where the DOM elements of a component need to be rendered to a location outside the parent component in the DOM tree, such as modal boxes, pop-up menus, tooltips, etc. React provides a powerful solution for this – Portals.

This article describes in detail the functions, implementation principles, and typical usage scenarios of React Portals to help developers better understand and use this feature.

What are React Portals?

React Portals is a feature introduced in React 16 that allows us to “route” the rendered content of a child component to another DOM node outside the DOM hierarchy of the parent component. This means that although the component logic and state remains in the React tree, its rendering results can be placed in any given DOM node.

The API provided by React is ReactDOM.createPortal(children, container) , the first parameter is the React node to be rendered, and the second parameter is the DOM container node.

The role and principle of Portals

  1. break the DOM level limit
    In React, components are usually rendered within the DOM structure of their parent component, which sometimes leads to limitations in style, layout, or event bubbling. Portals allow developers to render DOM nodes of child components to different DOM containers, thus breaking the hierarchy limit.
  2. Maintain the integrity of the React component tree structure
    although the actual rendering is in different DOM locations, React still maintains the parent-child relationship between components, and events still bubble normally according to The React event system, which does not damage the event mechanism inside React.
  3. Improve UI experience and layout control
    by rendering a modal box or pop-up layer on the outer DOM node (usually a div under the root node), you can avoid being restricted by the style of the parent container, such overflow: hidden or z-index occlusion problems caused.

Use Scenario Example

1. Modal box (Modal)

the modal box needs to cover the entire page or level above the root node. The modal box is rendered on a separate DOM node under the root node to avoid being constrained by local styles.

2. Pop-up menus and drop-down lists (Dropdown)

the pop-up menu needs to be freely positioned on the page to avoid being cropped due to overflow hiding or positioning of the parent element.

3. Tooltip

Tooltips usually need to be positioned absolutely away from the current layout, and Portals can be placed at the top of the page to ensure that they are not restricted by the layout.

4. Global Notification

notification tips are usually rendered in the top-level area of the page and do not rely on the component tree level, making it easy to manage display and animation.

Portals use considerations

  • event bubbling
    although the DOM structure is “transferred”, the event still bubbles from the child component to the parent component according to The React event system, and the developer can use Event Processing normally.
  • Style Isolation
    after rendering on different DOM nodes, additional style management may be required to ensure visual consistency.
  • DOM container node must exist
    the container node for creating the Portal must exist in the page DOM in advance, otherwise an error will be reported.

Summary

React Portals is an effective solution to the limitation of component rendering hierarchy, allowing developers to render child components to any node in the DOM tree other than the parent component. It ensures the normal operation of React event bubbling and facilitates the implementation of UI components that need to be free from layout restrictions, such as modal boxes, pop-up menus, and tool tips. The proper use of Portals helps improve component flexibility and user experience.

Interview answer

React Portals allows us to render child components to a specified DOM node outside the DOM level of the parent component, which can break through the DOM level restrictions while keeping the React component tree structure and event mechanism unchanged. Typical usage scenarios include modal boxes, pop-up menus, tooltips, and global notifications, requiring UI components that are freely positioned and displayed away from the parent container constraints. Through Portals,React can better manage component rendering and event bubbling, improving the flexibility and maintainability of UI components.
