Function and usage scenario of Object prototype hasOwnProperty()

foreword

in JavaScript object processing, it is often necessary to determine whether a property belongs to the object itself, rather than inheriting from the prototype chain. hasOwnProperty it is the core method to realize this judgment. Understanding its function and correct use are very important to prevent potential errors. This article will explain in detail hasOwnProperty function and application.

The role of hasOwnProperty

hasOwnProperty yes Object.prototype the method on is used to determine whether a property is an “own property” of the object itself, rather than an inherited property.

Syntax:

the return value is a Boolean, true indicates that the property is owned by the object itself, false indicates that the attribute does not exist or is from a prototype chain.

Why use hasOwnProperty?

In JavaScript, Objects inherit properties on the prototype chain. If no distinction is made, use for...inWhen the object is traversed, the properties on the chain including the prototype are traversed, resulting in a logical error.

Use hasOwnProperty you can filter out inherited properties and process only the properties of the object itself.

Use Example

when traversing the object, hasOwnProperty you can avoid handling inherited properties.

Precautions

  • object may have overridden or deleted hasOwnProperty method, which can be passed. Object.prototype.hasOwnProperty.call(obj, prop) to call, to ensure correct judgment.
  • ES6 was introduced. Object.hasOwn() is a static method with similar functionality and more security, and can also be used in modern projects.

Interview answer demonstration

question: “Please explain. hasOwnProperty why should I use it?”

“ hasOwnPropertyMethod is used to determine whether a property is owned by the object itself, rather than inherited from the prototype chain. Because in JavaScript, Objects inherit properties on prototypes, if you traverse or access properties directly, you may misoperate to inherit properties. Use hasOwnProperty these inherited properties can be effectively filtered out to ensure that only the properties of the object itself are processed.

In addition, note that the object may have overridden the method, recommend with Object.prototype.hasOwnProperty.call(obj, prop) to call, to ensure accuracy.”

summary

hasOwnProperty is an important way to determine whether the property belongs to the object itself, to avoid the inheritance of property interference code logic. Reasonable use of it, with traversal operations, can improve the accuracy and robustness of the code.
