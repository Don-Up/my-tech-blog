How are arrays and functions in JS stored in memory

Foreword

arrays and functions are the most commonly used data structures and units of execution in JavaScript. Understanding how they are stored in memory can help you better understand the language mechanics, improve performance, and avoid potential memory problems. This article will detail the principle of storing arrays and functions in memory and related details.

Memory storage of arrays

JavaScript arrays are essentially objects, with indexes as attribute names and elements stored as attribute values. But modern engines do many optimizations for arrays:

  • Dense Array
    when the array indexes are continuous and small, the elements are stored in continuous memory blocks, similar to traditional arrays, and the access speed is fast.
  • Sparse Array
    when the index is discontinuous or the array is too large, the elements are stored in the form of object-like attributes, and the performance is relatively poor.
  • Memory Layout
    array variables store references to heap memory array objects on the stack, which contain element data and related meta information.
  • Hidden classes and inline caching
    like objects, arrays may also use hidden classes to optimize element access.

Memory storage for functions

functions are also objects in JavaScript, with their own properties and methods:

  • the function object itself is stored in heap memory
    the function code, Scope chain, context, and other information are stored in the heap.
  • Variable storage
    The internal variables of the function are stored in the stack frame of the execution context. When called, the stack is entered and the stack is released after execution.
  • Closure reserved variables
    when a function forms a closure, the associated variables are kept in heap memory to prevent premature destruction.

Detail Description

  • the length property of an array is stored as a special property that affects the memory layout when accessed and modified.
  • The function execution environment maintains the scope chain and guarantees variable access.
  • Arrow functions do not have their own this , but its storage is similar to that of a normal function.

Summary

arrays and functions, as core data structures and execution bodies, have their own storage strategies and optimization methods in memory. A deep understanding of their memory model helps to write efficient and stable code.

Interview answer demonstration

question: How are arrays and functions in JS stored in memory?

Example answer:

“In JavaScript, arrays are essentially objects, but the engine optimizes dense arrays so that elements are stored in contiguous blocks of memory to improve access efficiency. The array variable itself stores a reference to the array object in heap memory. Functions are also objects, stored in heap memory, containing code and scope chain information. The execution context is created when the function is called, and the relevant variables are saved on the stack. Closures cause related variables to be saved in the heap, preventing premature destruction. These storage mechanisms ensure that JavaScript runs flexibly and efficiently.”
