How many ways does JavaScript have to determine the type of a variable (type detection)

Foreword

JavaScript is a dynamically typed language with flexible variable types. Correct determination of variable types is a common and important requirement in development, especially in function parameter verification, data processing, and debugging. This article will detail several commonly used and effective type detection methods in JavaScript, explaining their principles and applicable scenarios.

Common type detection methods

1. The typeof operator

typeof is the most basic type detection method that returns a string representing the type of a variable.

Common results include:

  • “undefined”
  • “boolean”
  • “number”
  • “string”
  • “symbol”
  • “bigint”
  • “function”
  • “object” (including null, array, object, etc.)

the disadvantage is that null returns “object”, unable to distinguish between arrays and ordinary objects.

2. instanceof operator

used to determine whether an object is an instance of a constructor.

The disadvantage is that the judgment of objects across different execution environments such as iframes may fail.

3. Object.prototype.toString.call()

this is a more accurate way of type detection and is suitable for distinguishing between various built-in object types.
