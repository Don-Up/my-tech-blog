What APIs does the Object have

Foreword

in JavaScript, Object is one of the most basic data types. It provides a variety of APIs for Object creation, attribute manipulation, inheritance, copy, and other functions. Understanding common methods and scenarios of objects can help developers operate objects more flexibly and efficiently and improve code quality.

This topic describes common Object APIs and their typical application scenarios.

Create and copy object-related APIs

  • Object.create(proto)
    creates a new object with the prototype pointing proto , which is often used to implement inheritance.
  • Object.assign(target, ...sources)
    copy the enumerable properties of the source object to the target object for shallow copying and object merging.
  • Object.freeze(obj)
    freeze the object to prevent the addition, deletion, or modification of attributes.
  • Object.seal(obj)
    A sealed object that prohibits adding or removing attributes, but allows modification of existing attributes.

Attribute Description and Operation

  • Object.defineProperty(obj, prop, descriptor)
    defines or modifies descriptors for object properties, suchwritable , enumerable , configurable and get/set .
  • Object.getOwnPropertyDescriptor(obj, prop)
    gets the descriptor for the specified property.
  • Object.keys(obj)
    gets an array of enumerable property names of the object itself.
  • Object.getOwnPropertyNames(obj)
    gets the names of all the properties of the object itself (including non-enumerable).
  • Object.getPrototypeOf(obj)
    gets the prototype of the object.
  • Object.setPrototypeOf(obj, proto)
    sets the prototype of the object.

Attribute judgment and detection

  • Object.hasOwn(obj, prop) (ES2022) determine whether the object itself has the specified property.
  • obj.hasOwnProperty(prop)
    detecting whether an object has its own properties.
  • prop in obj
    checks whether the property exists on the object itself or on the prototype chain.

Other Practical APIs

  • Object.entries(obj)
    returns an array of key-value pairs for the enumerable properties of the object itself.
  • Object.values(obj)
    returns an array of values for the enumerable properties of the object itself.
  • Object.is(value1, value2)
    determine whether two values are strictly equal, as distinguished from === , can handle correctly NaN and -0 .

Typical application scenarios

  • by Object.create implement prototype inheritance.
  • Use Object.assign object merge and shallow copy.
  • By Object.defineProperty implement access control for properties (e. G., read-only, computed properties).
  • Use Object.freezeAnd Object.seal protects objects from being accidentally modified.
  • Binding Object.keys , Object.entries handle object data traversal.
  • Use Object.getPrototypeOf and Object.setPrototypeOf operate the prototype chain.

Interview answer

Object provides a variety of APIs for creating, modifying, and detecting Object properties.

Commonly used include Object.create create a prototype chain, Object.assign implements object merging, Object.freeze and Object.seal used to freeze and seal objects. Object.defineProperty you can fine-grained control over writable, enumerable, and accessors for properties.

When Judging attributes, you can usehasOwnProperty or in operator, ES2022 added Object.hasOwn , more concise.

In addition, Object.keys , Object.entries and Object.values used to traverse object properties and data.

Summary

javaScript’s Object API involves Object creation, attribute definition, inheritance, detection, and freezing. The proper use of these interfaces can help developers manage object data structures efficiently and ensure code quality and performance. Understanding the usage scenarios of these APIs is an important foundation for front-end development.
