CSS drawing triangles

foreword

CSS drawing triangles is a classic technique, often used to make arrows, prompt bubbles, indicators and other interface elements. This method does not rely on the picture, by using the border characteristics of the elements, simple and efficient implementation of various directions and sizes of the triangle.

The principle of drawing triangles

triangles are usually implemented by setting borders of different colors and opacity to a zero-width and zero-height element. The size of the element itself is zero, but the width of the border can be set. By setting the three borders to transparent and the remaining border to set the color, the visual effect of a triangle is presented.

For example, to make an upward triangle, you can set the element width and height to 0, and then set:

  • the top border is transparent
  • left and right borders are transparent
  • bottom border set color and larger width

in this way, only the bottom border displays color, forming an upward triangle.

Code Sample

the above style produces an isosceles triangle with a red base, pointing upwards.

Triangles in other directions

  • down: Setting border-top there is color, the rest is transparent.
  • Left: Setting border-right there is color, the rest is transparent.
  • Right: Set border-leftThere is color, the rest is transparent.

The width and height are controlled by the width of the border, which can be flexibly adjusted in size and scale.

Interview answer

CSS drawing triangles use elements with zero width and height to form a triangle effect by setting three borders to be transparent and one border to set color. Set the border color in different directions according to the needs, and can make triangles in various directions, which are widely used in arrows and indicator signs.

Summary

using the combination of transparent border and color, CSS can easily draw triangles of various directions and sizes, which is both concise and efficient. Mastering this technique can reduce image dependence and improve page loading speed and flexibility.
