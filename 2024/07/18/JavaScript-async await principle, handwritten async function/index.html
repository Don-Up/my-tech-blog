async await principle, handwritten async function

Foreword

async/await is a sharp weapon for complex asynchronous processes in modern JavaScript processing. It is based on promises and uses synchronous writing to represent asynchronous operations, greatly improving the readability and maintainability of the code. An in-depth understanding of the principles of async/await and the process of writing async functions will help you fully grasp the underlying mechanisms of asynchronous programming.

Basic principles of async/await

the async function returns a Promise, and The await expression pauses the async function execution, waits for the Promise to be resolved, resumes execution, and returns the result.

In essence, an async function is a combination of a Generator function and a Promise. The JavaScript engine converts the async function into a Generator function, and then uses an actuator to automatically drive the Generator to manage asynchronous processes.

Specific performance is:

  • async function execution returns a Promise immediately
  • the expression after await is wrapped by Promise.resolve
  • the function pauses and waits for the Promise to be resolved. When it resumes, it gets the result and continues to execute.
  • If await’s Promise is rejected, an exception will be thrown, which can be caught with try/catch.

Interview answer

the async function is syntactic sugar, essentially a combination of a Generator function and a Promise. When the async function is executed, a Promise is returned. await is used to pause execution in the function body and wait for the Promise to be resolved.

The key to handwriting async is to implement an executor. This executor automatically calls the Generator’s next method, gets a Promise at a time, then waits for it to resolve, and then continues to call next until the Generator is executed and finally returns a Promise.

This executor implementation should be able to handle exceptions, catch errors during Generator execution through try/catch, and pass them through Promise’s reject.

Understanding the principles of async/await helps you gain a deeper understanding of asynchronous programming, especially debugging complex asynchronous code and optimizing asynchronous processes.

Summary

async/await greatly improves the readability of asynchronous code, which is essentially a combination of Generator functions and promises. The handwritten async function needs to implement a function that automatically executes the Generator, recursively processing the Promise of each step. An in-depth understanding of its principles can help you better use and debug asynchronous code, as well as facilitate understanding of the underlying execution mechanism.
