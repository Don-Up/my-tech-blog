Describe the Iterator Iterator and what its use is

Foreword

Iterator is a protocol used in JavaScript to traverse data structures, which greatly enriches the language’s ability to handle collection types. Understanding how iterators work and are used is essential to mastering the language features of ES6 and beyond. This article will introduce the concept, implementation and typical applications of iterators.

Definition and Principle of Iterator

an iterator is an interface that defines the uniform methods required to traverse a data structure. At its core is a next() method, each call returns an object with two properties:

  • value the value of the current traversal
  • done : A Boolean value that indicates whether the traversal is completed.

An object as long as it implements next() method, which is an iterator.

ES6 introduced the iterator protocol and passed. Symbol.iterator connect an iterator to an iterable object.

Iterable objects and iterators

an iterable object is one that implements Symbol.iterator the object of the method. Calling this method returns an iterator object that supportsfor...of syntax such as extension operators.

uses of Iterators

iterators allow us to customize our traversal logic, which can be used to implement:

  • custom data structure traversal
  • generate an infinite sequence
  • on-demand or lazy evaluation
  • with for...of loop with simple traversal
