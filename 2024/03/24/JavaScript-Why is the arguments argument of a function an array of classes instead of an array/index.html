Why is the arguments argument of a function an array of classes instead of an array

Foreword

function in JavaScript has a special object inside arguments which is used to access all parameters passed in when the function is called. Although it resembles an array, it is not really an array, but an “array-like” object. Understand why arguments it is a class array rather than an array, which helps to have a deeper understanding of JavaScript’s function call mechanism and parameter handling.

Features of arguments

arguments object has the following characteristics:

  • store the value of each parameter with a numeric index as an attribute.
  • There are length property represents the number of parameters.
  • Does not have array methods such push , pop , forEach wait.
  • No. Array examples, arguments instanceof Array forfalse .

These properties make it more like an “array-like” object.

Why not an array?

1. Historical design reasons

arguments it is a special object implemented in the early design of JavaScript to support dynamic parameter passing. Instead of using an array structure, it is designed in the form of a class array, which is convenient for storing parameters and has less performance overhead.

2. Compatibility and performance considerations

in early browsers and JavaScript engines, implementing an array completely required additional performance overhead. Class array objects are more lightweight and can meet the needs of access parameters.

3. Special relationship with function parameter binding

arguments there is a mapping between elements in and functional parameters (in non-strict mode), and modifying one affects the other. This behavior is not naturally supported by arrays.

Arrays cannot support this special binding relationship.

Interview answer

question: Why is the arguments argument of a JavaScript function an array of classes instead of an array?

Answer demonstration:

arguments is a class array object, designed to access function parameters lightly, and there is a special binding between function parameters, modifying parameters in non-strict mode will affect arguments . It is not an Array, is missing an Array method and is not an Array instance. Historical compatibility and performance reasons also prompted its design as an array of classes. After ES6 recommend use the remaining parameters, it is a standard array, more flexible and clear semantics.

Summary

arguments as a class array object, it is the product of the early design of JavaScript, which has both lightweight and special binding functions to meet the needs of dynamic parameter access. Understanding the difference between them and arrays helps to use parameter access methods and conversion techniques correctly. Modern development should give priority to the use of remaining parameters in order to obtain stronger array manipulation capabilities and clearer code expression.
