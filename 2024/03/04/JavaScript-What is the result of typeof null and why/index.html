What is the result of typeof null and why

Foreword

typeof it is the basic operator in JavaScript to determine the type of a variable, but its performance in some cases is misleading, especially typeof null return "object" this seemingly contradictory result often confuses developers. This article will explain in detail typeof null return "object" reasons and the historical background behind it.

Why typeof null returns “object”

according to intuition, null represents “no value” or “null value”, which should be recognized as a separate type. But in JavaScript, typeof null return is "object" .

This is because when JavaScript was originally designed, the type of the underlying value was identified by a single binary bit. nullThe internal representation of is a null pointer, which is a tagged pointer of the object type. In earlier implementations, all values pointing to objects were marked "object" , and null as an object pointer to a null, it is also classified "object" .

This design has become a historical problem. Subsequent versions of the language have not corrected this behavior and continue to retain it for compatibility.
