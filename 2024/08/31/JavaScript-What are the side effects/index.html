What are the side effects

Foreword

in programming, “Side Effects” is a core concept, especially in functional programming is particularly important. Understanding side effects can help you write more maintainable and reliable code. This article describes the definition of side effects, common manifestations, and how to avoid or manage side effects in JavaScript.

What are side effects

A side effect is an observable change or effect on the external state of a function or expression during execution, in addition to the return value. In other words, a side effect is a function that, after execution, affects the environment or state outside the function.

Side effects include, but are not limited:

  • modifying global or external variables
  • modifying incoming parameters (mutable objects)
  • operation DOM
  • trigger a network request or write a file
  • throw an exception or call the system API

side effects are opposed to pure functions, which execute only on input parameters and have no side effects.

why Side Effects Should Be Concerned

  • increased debugging difficulty: Side effects hide state changes that are difficult to track.
  • Reduces code testability: Side effects make functions dependent on external state and are not easily tested separately.
  • Affect code maintainability: Side effects lead to chaotic state, making it difficult to predict program behavior.

How to Avoid or Manage Side Effects

  • pure functional programming style, try to avoid modifying the external state.
  • Use immutable data structures to prevent accidental modification.
  • Centralized management of side-effect code, for example, using specialized side-effect handling mechanisms (such as middleware in Redux, RxJS, etc.).
  • Clarify function responsibilities and separate side-effect logic from pure computational logic.

Interview answer demonstration

question: “What are the side effects? Why care about it?”

“Side effects refer to the execution of a function that, in addition to the return value, also affects external state, such as modifying global variables, changing incoming objects, manipulating DOM, or sending requests. Side effects increase code complexity, making it difficult to predict and debug.

In order to write more robust code, it is common to use pure functions to avoid side effects, or to centralize the management of side effect logic. This improves the testability and maintainability of the code.”

summary

side effects are external state changes brought about by function execution. Although they are inevitable, proper management and control of side effects is the key to improving code quality. Understanding side effects can help you write programs that are more predictable and maintainable.
