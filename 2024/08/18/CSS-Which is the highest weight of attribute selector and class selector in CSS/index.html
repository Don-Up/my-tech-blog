selector weights in CSS determine how the browser selects the style that ultimately takes effect when multiple style rules apply to the same element. Property selectors (such [type="text"] ) and class selectors (such .className ) are two common selector types, and understanding their weight differences is critical for style coverage and debugging.

Weight calculation for attribute selectors and class selectors

in the CSS priority calculation, the attribute selector and the class selector belong to the same rank and have the same weight. Specifically, they all count as a “class selector”, and the count items in the priority calculation are the same.

The basic rule of priority is represented by four numbers: a (in-line style), B (ID selector), c (class selector, attribute selector, pseudo-class selector), d (element selector, pseudo-element selector). Both the attribute selector and the class selector count toward the c-bit.

Therefore, if two rules use the attribute selector and the class selector respectively, and the other parts are the same, their priorities are equal, and the browser will decide which rule is finally applied according to the order of appearance, and the rule that appears later takes precedence.
