📌 What is _document.js in Next.js?

In the Pages Router (pages/ directory), _document.js (or _document.tsx) is a custom Document component that overrides the default HTML structure generated by Next.js. It allows you to customize the <html>, <head>, and <body> tags.

🚨 _document.js is NOT used in the App Router (app/ directory).
In the App Router, use layout.tsx instead.

✅ When to Use _document.js?

You should use _document.js only if you are using the Pages Router and need to:

  • Customize the <html> or <body> tags.
  • Add global attributes (e.g., lang, data-theme).
  • Inject third-party scripts (e.g., Google Fonts, analytics) outside of next/head.

✅ Explanation

Element Purpose
<Html> Wraps the entire document (<html> tag). You can set attributes like lang="en".
<Head> Used for meta tags, fonts, or scripts. (❗ But use next/head in pages for dynamic metadata).
<body> Wraps the main content. You can set a CSS class or global attributes.
<Main> Renders your Next.js page content.
<NextScript> Loads Next.js scripts for functionality. Must be included.

❌ _document.js Does NOT Work in App Router (app/)

If you’re using the App Router (app/ directory), do NOT create _document.js.
Instead, use layout.tsx.

✅ App Router Alternative: layout.tsx

🚀 Summary

Feature Pages Router (pages/) App Router (app/)
Customize <html> & <body> ✅ Use _document.js ✅ Use layout.tsx
Set <head> meta tags ✅ Use next/head in pages ✅ Use generateMetadata or head.tsx
Include global fonts/scripts ✅ Use <Head> in _document.js ✅ Use <head> inside layout.tsx

🔹 Use _document.js only in the Pages Router.

For the App Router, use layout.tsx instead. 🚀
