What are the phases of the lifecycle of an execution context

Foreword

understanding the life cycle of the execution context is the key to a deep understanding of the JavaScript code execution process. The execution context is not only the execution environment of the code, but also changes in multiple stages, affecting variable initialization, function declaration, and scope chain construction. This article will disassemble the various stages of the execution context life cycle in detail to help you better understand how the JS engine executes code, and also provide professional answer reference for interviews.

Lifecycle phase of the execution context

the life cycle of an execution context can be roughly divided into two main phases: the creation phase and the execution phase.

1. The creation phase (also known as the “variable object initialization phase”)

at this stage, the JavaScript engine does several things:

  • create a Variable Object (VO) to store variables declared within a function and function declarations
  • parsing function declarations, binding function names to variable objects
  • variable declaration promotion, the variable is declared but unassigned, initialized undefined
  • establish a scope chain, through which the execution context points to the current variable object and the variable object of the external context.
  • Determine this point

at this stage, variable promotion and function promotion occur here, so that function declarations and variable declarations can be called before the code.

2. Implementation phase

After the creation is complete, the execution context enters the execution phase, and the code is executed line by line:

  • the variable assignment takes effect, and the assignment of the function expression is completed at this stage.
  • The function body in the code starts executing
  • variables and functions are gradually initialized to concrete values for subsequent code use.

3. Destruction of the execution context

when the function is executed or the global code is executed, the corresponding execution context is popped from the execution context stack, and the life cycle ends.

Note that closures cause some variable objects in the execution context to not be destroyed immediately because they are still referenced.

The relationship between variable promotion and execution context

variable promotion is essentially part of the creation phase. Variable and function declarations are registered in advance in the variable object, but variable declarations are only declared unassigned, and function declarations are fully registered.

Interview answer

question: What are the phases of the life cycle of an execution context?

Answer demonstration:

The life cycle of an execution context is divided into two phases, the creation phase and the execution phase. When creating the phase, JavaScript creates the variable object, promotes the function declaration and variable declaration into the variable object, establishes the scope chain, and determines the this point. The execution phase is where the code is executed line by line, the variable assignment takes effect, and the function body is executed. When execution completes, the execution context is popped from the call stack. Understanding these two phases helps you understand variable promotion, Scope chain formation, and code execution order.

Summary

the lifecycle of the execution context directly affects JavaScript variable promotion, Scope chain construction, and code execution flow. Mastering the two stages of creation and execution will help you understand the operating mechanism of JS and troubleshoot complex scopes or variables. Expressing these concepts clearly in the interview demonstrates your professionalism.
