API Routes in Next.js

2024-01-03
#API-Routes
Next.js

API Routes in Next.js allow you to create backend endpoints directly inside your Next.js application. These routes run on the server and can handle requests like a traditional API.

1. How to Create an API Route

API routes are stored inside the /pages/api/ directory (for the Pages Router).

2. Handling Different HTTP Methods

API routes support GET, POST, PUT, DELETE, etc..
Use req.method to check the request type.

6. API Routes Do NOT Work in the App Router (app/)

  • API Routes (/pages/api/) work only in the Pages Router.
  • If you’re using the App Router (app/ directory), use Route Handlers (app/api/route.ts) instead.

Feature API Routes (/pages/api/)
Server-side code (backend logic) Yes
Handles GET, POST, PUT, DELETE Yes

Dynamic API routes (/api/user/[id]) Yes
