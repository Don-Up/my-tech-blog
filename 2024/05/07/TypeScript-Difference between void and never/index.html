Difference between void and never

Foreword

in TypeScript, void and never are special types that are often used to describe the return type of a function. They are all related to the “no return value” or “no result” after the function is executed, but there are obvious differences in semantics and application scenarios. Understanding void and never this helps to accurately express function behavior and type constraints, thus improving the Type safety and readability of the code. This article will explain in detail the definition, difference and application scenarios of these two types.

oid Type Resolution

void usually used to describe a function that does not return a value, that is, the function does not return any meaningful value after execution. It is equivalent to returning in JavaScript undefined fNunction. void variables of type can generally only be assigned undefined (In strict mode).

void it can also be used as the return type of generic constraints and callback functions, indicating that there is no specific return value.

Never type resolution

never A type that never returns a value and is used to describe functions that never end normally. Typical scenarios include:

  • the function that threw the exception
  • function of a dead loop

in addition, never it also represents the empty set of type convergence, which is used for “exhaustive checking” in type protection “.
