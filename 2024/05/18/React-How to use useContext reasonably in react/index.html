How to use useContext reasonably in react

Foreword

React in useContext it is a convenient way to transfer data across components, avoiding the cumbersome layer-by-layer transfer of props. It allows developers to access shared context data at any level in the component tree. Although easy to use, but unreasonable useContext use can cause performance problems or code maintenance difficulties.

This article will be from useContext the basic principles, rational use of methods, performance optimization strategies and typical examples to help you understand and use them efficiently. useContext .

Basic principles of useContext

useContext is a Hook of React, which is used to subscribe to The React Context object. Context React.createContext create a Provider that wraps the component tree and passes shared data to its descendants. Use useContext after that, the component will subscribe to the Context. Once the value passed by Provider changes, all components using this Context will be re-rendered.

Simplify the process:

  1. byReact.createContext(defaultValue) create the Context object.
  2. Use <Context.Provider value={...}>wrap the component tree and pass in the shared data.
  3. Called in a child component const contextValue = useContext(Context) gets the context value.

Key Points of Reasonable Use of useContext

1. Use only on states that need to be shared

useContext ideal for managing state that is passed globally or across multiple layers, such as subject, user authentication information, language settings, and more. For local or single-layer data delivery, it is recommended to still use props to reduce the risk of unnecessary re-rendering.

2. Avoid using objects that are too large or change frequently as Context values.

A change in the value of a Context causes all components that subscribe to that Context to be re-rendered. If the passed-in object is large or changes frequently, it can cause a performance bottleneck. It is recommended to split the Context or localize the state.

3. Use memoization to cache Context values

avoid creating a new Context value object every time you render. By useMemoThe cache ensures that it is updated only when the dependency changes.

avoid using a single Context in a large component tree

subdivide the Context into multiple small contexts and maintain them separately for different needs. This reduces repetitive rendering of unrelated components.

Performance Optimization Tips

the Context mechanism of React is implemented based on reference comparison, only when Provider’s value subscribers will only be updated when there is a change. Common optimization methods include:

  • split the Context to reduce the subscription scope.
  • Use React.memo or useMemo cache components and Context values.
  • Place infrequently changing Context values separately to avoid frequent updates.
  • Use a selector library (such use-context-selector ) for finer-grained subscriptions.
