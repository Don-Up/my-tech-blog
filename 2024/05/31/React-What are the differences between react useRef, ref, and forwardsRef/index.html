What are the differences between react useRef, ref, and forwardsRef

Foreword

in React development, when operating on DOM or accessing component instances, ref mechanisms play an important role. At the same time, React provides multiple ref related APIs, such useRef , ref property and forwardRef . There are differences in usage scenarios, functions and implementation mechanisms, but they are often confused in actual development.

This paper will explore in depth useRef , ref and forwardRef the concepts and differences, combined with specific code examples, help you clarify their role and application scenarios, so as to improve the understanding of the reference and communication between React components.

ref is the mechanism that React uses to reference DOM elements or component instances. By adding to the React element ref property, you can get a reference to the element, easy to operate DOM or access class component instances.

useRef is an API in React Hooks that is used to create variable reference objects in function components. It returns a variable .current property, the component maintains the same reference across multiple renderings.

Main purpose:

useRef is the React Hook, which is used to create a mutable reference object in the function component, usually used to hold DOM nodes or any mutable data that does not affect rendering. It does not trigger the component to re-render.
