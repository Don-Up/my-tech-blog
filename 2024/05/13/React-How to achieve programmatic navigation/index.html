How to achieve programmatic navigation

Foreword

in modern single-page application (SPA) development, navigation is a core component of the user experience. In addition to the traditional click link jump, sometimes business logic needs to actively trigger page jump according to conditions or events, then you need to use “programmatic navigation”. In React applications, especially when using React Router, programmatic navigation allows developers to dynamically control route jumps through code, thus realizing more flexible interaction process and navigation experience.

This article focuses on “How to Implement Programmatic Navigation” and introduces in detail the core method of implementing programmatic navigation in React Router, with code examples and usage scenarios to help readers fully understand and apply it flexibly.

What is Programmed Navigation?

Programmatic navigation means that it does not depend on the user clicking <Link>or <a>label, but through the program code to control the way the browser routes jump. It is common in the following scenarios:

  • after successful login, the user will automatically jump to the home page or personal homepage.
  • Jump to the results page after form submission
  • redirect to different pages based on permissions or conditions
  • timed or event-triggered automatic jump

with declarative navigation (using <Link to="...">), programmed navigation is more flexible and controllable.

II. Implementation of Programming Navigation In React Router

1. UseuseNavigate hook(React Router v6)

in React Router v6, you recommend use useNavigate Hook to implement programmatic navigation. It returns a navigate function, call the function to trigger a route jump.

Code Sample

navigate function supports the following usages:

  • navigate('/path') : Jump to a specified path
  • navigate(-1) rewind to previous page (equivalent to browser back)
  • navigate('/path', { replace: true }) : Replaces the current history without generating a new history.

2. Use history object (React Router v5 and before)

in React Router v5, you can access history object to implement programmatic navigation. There are two common ways:

  • by withRouterHigh-order component injection history and then call history.push('/path')
  • by useHistory Hook acquisition history object, calling history.push or history.replace
