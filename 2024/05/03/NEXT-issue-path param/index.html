⚠️ The Problem

When I accessed http://localhost:3000/api/comments/e2, I expected eventId to be "e2", but instead, it was null.

🧐 Why is eventId Null?

The issue here is how searchParams works:

  • searchParams only extracts query parameters from the URL (i.e., the ?key=value part).
  • However, e2 in /api/comments/e2 is a path parameter, not a query parameter.
  • Since req.url only contains the relative path (/api/comments/e2), new URL(req.url) fails to parse it correctly.

But if the URL were /api/comments?eventId=e2, then searchParams.get('eventId') would return "e2" correctly.
