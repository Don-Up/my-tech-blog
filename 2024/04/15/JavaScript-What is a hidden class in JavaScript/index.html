What is a hidden class in JavaScript

Foreword

as a dynamic language, JavaScript’s object structure can be flexibly changed at runtime. To improve performance, modern JavaScript engines use Hidden Class mechanisms internally to optimize object property access. Understanding the concept and role of hidden classes will help you gain insight into performance optimization principles and how to write efficient code.

This article details the definition of hidden classes, the generation process, and the impact on performance.

What is a hidden class?

Hidden classes are internal data structures designed by the JavaScript engine to speed up access to object properties. It is similar to the “class” or “structure” in traditional object-oriented languages, describing the layout and memory structure of object properties.

The properties of JavaScript objects are dynamically added at runtime, and hidden classes allow the engine to create corresponding hidden classes for each property structure of the object, thus enabling fast property access.

Generation and Transformation of Hidden Classes

when an object is created and attributes are added, the JavaScript engine dynamically generates the corresponding hidden class based on the order and name of the added attributes.

If the properties are added in a different order, or if there are additional properties, the hidden class is converted to generate a new hidden class.

Performance Impact of Hidden Classes

  • quick Property Access
    objects that share the same hidden class can quickly access properties through fixed offsets instead of looking up hash tables, improving access efficiency.
  • Optimize memory layout
    hidden classes help the engine store the properties of an object in contiguous memory, improving cache hit rates.
  • Hidden Class Conversion Cost
    dynamically changing the object structure will lead to hidden class conversion, increase overhead, and affect performance.

Recommendations for writing high-performance code

  • try to keep the same kind of object attributes added in the same order.
  • Avoid frequent dynamic addition or deletion of object properties.
  • Use factory functions or class constructors to create object structures uniformly.
  • Try to use fixed-structure objects to reduce hidden class conversions.

Interview answer

A hidden class is a data structure maintained internally by the JavaScript engine to optimize access to object properties. It is similar to a class, describing the layout and storage location of an object’s properties.

When object properties are added, the engine generates or transforms hidden classes so that objects with the same structure share hidden classes for fast property access and memory optimization.

Frequent dynamic modification of object properties will lead to frequent conversion of hidden classes and reduce performance. Therefore, it is recommended to keep the object attribute structure consistent to avoid dynamic changes and improve code efficiency.

Summary

Hidden classes are an important mechanism for the JavaScript engine to achieve efficient object access. It enables fast property access and memory optimization by maintaining internal class definitions for similarly structured objects. Reasonable design of object structure, reduce hidden class conversion, can significantly improve the performance of JavaScript code.
