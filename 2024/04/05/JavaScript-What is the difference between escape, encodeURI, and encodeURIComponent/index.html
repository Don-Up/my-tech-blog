What is the difference between escape, encodeURI, and encodeURIComponent

Foreword

in Web development, URL encoding is a common requirement to handle special characters to ensure the legitimacy of URLs. JavaScript provides several encoding functions: escape , encodeURI and encodeURIComponent . Understanding their differences and usage scenarios can help you code URLs correctly and avoid potential problems.

Features and limitations of escape

escape is an earlier encoding function and is no longer recommend to use. It encodes characters other than ASCII alphanumeric, but has insufficient support for Unicode characters.

Role of encodeURI

encodeURIIs used to encode the entire URI, but retains special characters in the URI such : , / , what? , & , = etc. To ensure the integrity of the URI structure.

encodeURI does not encode the URI delimiter and is suitable for encoding the complete URL.

The role of encodeURIComponent

encodeURIComponent used to encode URI components, such as query parameter values, encode most characters except alphanumeric, including separators.
