What is the difference between display none And visibility hidden

foreword

in front-end development, the need to hide elements is very common. display: none; with visibility: hidden; are two commonly used hiding methods in CSS, but they differ significantly in the layout footprint and rendering mechanism of elements. Understanding the difference between the two helps to choose the correct hiding scheme and avoid layout confusion and interaction anomalies.

Behavioral characteristics of display: none

when the element sets display: none; the browser completely removes the element from the document flow. Elements neither occupy any space nor participate in the page’s drawing and interaction events. This means that the element does not exist on the page, and subsequent elements automatically fill its position.

Therefore, using display: none; it affects the page layout and is suitable for scenarios that need to be completely hidden without occupying space, such as switching the content of a tab page and dynamically hiding modules.

visibility: behavior characteristics of hidden

setup visibility: hidden;Will make the element invisible, but the element remains in the document flow and occupies its original spatial position. The element does not display content or respond to mouse events, but its box model dimensions still affect the surrounding layout.

This makes visibility: hidden; it is suitable for scenes that need to hide visual content but keep the layout structure unchanged, such as hiding buttons without changing the overall layout to avoid page jitter.

Comparative summary

  • space usage: display: none; does not take up space, visibility: hidden; take up space.
  • Interactive Response: display: none; the element does not participate in the interaction; visibility: hidden; the element is not visible and does not respond to mouse events.
  • Layout impact: display: none; will trigger a layout rearrangement, visibility: hidden; the layout size is not affected, but the content is not visible.
  • Animation support: visibility it can be matched with animation such as transparency and position,display animated transitions are not supported.

Interview answer

display: none; it will allow elements to be completely removed from the document flow without taking up space or participating in interactions, which is suitable for completely hiding elements; And visibility: hidden; the element remains a placeholder but not visible, and does not respond to mouse events, making it suitable for hiding content but keeping the layout intact. The main difference between the two is whether to occupy space and the impact on the layout.

Summary

understanding display: none; and visibility: hidden; the difference helps to hide elements correctly under different needs, ensuring Page Layout stability and user experience. Reasonable choice of hiding mode is an important part of front-end layout and interaction design.
