The parent component of react calls the methods of its child components

Foreword

the interaction between parent and child components is a very common requirement during React development. In addition to passing data through props, parent components sometimes need to call methods of child components directly to trigger specific actions. Due to the encapsulation of the React component, the parent component cannot directly access the instance methods of the child component by default, so some special technical means are required to implement this function.

This article describes in detail the common methods and principles of parent components calling child component methods in React to help developers better understand and master this technique.

Challenges for Parent Component Calling Child Component Methods

the React component design emphasizes one-way data flow. The parent component transmits data to the child component through props, and the child component notifies the parent component through callback. However, sometimes the parent component needs to actively trigger the behavior of the child component, such as focusing the input box, calling the business method of the child component, and so on.

For class components, the parent component can pass. ref gets the child component instance, calling its instance method. However, the function component has no instance and cannot be passed directly. ref call the method. To solve this problem, React provides forwardRef and useImperativeHandle to assist in the implementation.

Option 3: Pass the trigger function through the callback function (not recommended for “calling sub-component methods”)

sometimes developers pass functions to child components through props, and then the child component indirectly calls the child component behavior by exposing function callbacks to the parent component, but this method brings some complexity and is not clear enough in semantics. Compared to direct use ref it is more recommend to use the first two schemes.

summary

it is common for a parent component to call a child component method in React development, but due to the design concept of React, you need to use ref , forwardRef and useImperativeHandle mechanisms to achieve. Class components can be used directly with ref get the instance and call the method, the function component needs to pass. forwardRef cooperation useImperativeHandle explicit exposure methods. The rational use of these technologies can meet the complex interaction requirements while ensuring the encapsulation of components.

Interview answer

in React, the parent component calls the child component method, and the class component can pass. refObtain a child component instance and call its public methods; forwardRef and useImperativeHandle implement the parent component through ref call a method inside the child component. This not only ensures the encapsulation of the component, but also allows the parent component to actively control the behavior of the child component. Callback function passing can achieve similar functionality, but it is not semantically clear enough and is usually not recommend to call child component methods directly.
