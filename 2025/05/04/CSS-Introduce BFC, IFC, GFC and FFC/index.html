Introduce BFC, IFC, GFC and FFC

Foreword

in the realm of CSS layout, it is important to understand the various Formatting contexts. BFC (block-level formatting context), IFC (in-line formatting context), GFC (table formatting context), and FFC (flexible box formatting context) correspond to different layout modes, which determine how elements are arranged, how other elements are affected, and how containment relationships are handled. Mastering them helps to solve layout problems and optimize page structure.

Introduction to various formatting contexts

BFC(Block Formatting Context)

BFC is a block-level layout environment in which block-level boxes are arranged according to specific rules. A common way to create a BFC is to set float not none , position for absolute or fixed , display for flow-root wait.

The main feature of the BFC is that the internal element layout does not affect the external elements, and the BFC contains its internal floating elements to prevent height collapse. At the same time, BFC can prevent the outer margins from overlapping.

IFC(Inline Formatting Context)

IFC is responsible for the layout of in-line elements, including text and in-line block elements. In IFC, elements are arranged from left to right (or the corresponding writing direction) according to the text flow, supporting line wrapping and text typesetting. IFC handles the arrangement of in-line elements such as text and pictures.

GFC(Table Formatting Context)

GFC is used for table layout to control the arrangement of rows, columns and cells of a table. Table elements such <table>, <tr>, <td>are in GFC, make sure the table is displayed correctly according to row and column rules.

FFC(Flex Formatting Context)

FFC is the flexible box layout context. Elements are arranged according to the flexible box model and support flexible alignment, scaling, and space allocation. By setting the parent element’s display: flex or inline-flex created. FFC addresses the complex typesetting requirements that are difficult to achieve with traditional layouts.

Application Value of Formatting Context

Understanding the behavior of different formatting contexts helps developers use floating, positioning, and flexible box layouts reasonably, avoid layout conflicts, solve common problems such as height collapse and margin merging, and improve page stability and expressiveness.

Interview answer

BFC, IFC, GFC, and FFC are block-level, inline, table, and flex-box formatting contexts, respectively. BFC creates a block-level layout environment to prevent overlapping margins and containing floats; IFC is responsible for the arrangement of elements in the row; GFC handles table row and column layout; FFC is a flexible box layout environment that supports flexible space allocation and alignment. Understanding them can help solve various layout problems.

Summary

formatting context is the core mechanism of CSS layout. In-depth understanding of BFC, IFC, GFC and FFC can help developers more accurately control the layout of elements, avoid layout traps, and improve page compatibility and user experience. Mastering these concepts is an important step in advanced CSS layout.
