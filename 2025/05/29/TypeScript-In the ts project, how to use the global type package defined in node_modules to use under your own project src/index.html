Introduction to Global Type Package

A global type package is a type declaration file that does not require an explicit import to take effect, typically .d.ts files, directly extending or declaring global variables, interfaces, types, etc. Such @types/node provide a type declaration for the Node.js global object, which can be used directly from anywhere in the project after installation.process , Buffer and other types.

These global type packages are installed by default in node_modules/@types directory.

The default behavior of TypeScript.

TypeScript is automatically scanned by default node_modules/@types all types under the folder declare packages and are imported as global types. That is, if you don’t have a special configuration tsconfig.json of types or typeRoots as long as the global type package is installed correctly, the project src the code below will be able to access these types directly.
