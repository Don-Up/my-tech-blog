The difference between null and undefined, how to make a property null

Foreword

null and undefined are two common data types that represent “no value” in JavaScript, and many beginners often confuse them. Understanding the difference between the two and their semantics helps to correctly handle the state of variables and object properties. This article will be in-depth analysis null and undefined and explain how to assign object properties null .

Difference between null and undefined

definition and semantics

  • undefined
    indicates that the variable is declared but not assigned, and is the default initial value given by the JavaScript runtime. For example, when a variable is declared but not initialized, and the function does not return a value, the default return is undefined which also returns when accessing a property of an object that does not exist undefined .
  • null
    indicates “no value” or “null value”, which is a special value that the developer actively assigns to a variable or attribute to indicate that the variable has no value.

Type

undefined is one of the basic types of JavaScript; null in typeof return under operator "object" this is a legacy of history, null is treated as a special null reference value.

Use Scenario

  • undefined more used as a variable is not assigned, the property does not exist, the function has no return value identification.
  • null used as an explicit null value, indicating that the variable is defined but temporarily has no value, usually manually assigned by the programmer.
