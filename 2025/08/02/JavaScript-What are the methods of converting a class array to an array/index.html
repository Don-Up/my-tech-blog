What are the methods of converting a class array to an array

Foreword

in JavaScript, we often encounter “array-like” data structures, such arguments object, DOM query result NodeList wait. Although these objects have length and numeric indexes, but not really arrays, so you can’t use the array method directly. At this point, it becomes important to know how to convert a class array into a real array, especially in front-end development with frequent data processing or traversal requirements.

Why you need to convert class arrays

although class arrays have the structural characteristics of arrays, they cannot directly use the prototype methods of arrays, such map , filter , reduce wait. Calling these methods directly will report an error or behavior exception. Converting it to an array unlocks the power of all arrays, making the code more concise, efficient, and easy to maintain.
