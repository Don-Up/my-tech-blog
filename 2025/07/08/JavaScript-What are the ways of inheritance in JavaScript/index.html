What are the ways of inheritance in JavaScript

Foreword

inheritance is one of the core concepts of object-oriented programming, JavaScript as a prototype-based language, inheritance mechanism is different from traditional class inheritance. Understanding the various inheritance methods of JavaScript will help you write more flexible and efficient code. This article will systematically introduce the common inheritance methods in JavaScript and their advantages and disadvantages.

Analysis of Common Inheritance Methods

prototype Chain Inheritance

by having the prototype of the child class point to an instance of the parent class, the implementation inherits the parent class properties and methods.

Advantages: Simple, able to inherit all properties and methods of the parent class.

Disadvantages: Reference type properties are shared by all instances.

Borrowing constructor inheritance (classic inheritance)

the parent constructor is called inside the child constructor, borrowing its scope.

Advantages: Solves the problem of reference type sharing and can pass parameters.

Disadvantages: The methods are defined in the constructor and cannot be reused.

Combined inheritance

combining the advantages of prototype chain inheritance and borrowing constructor inheritance.

Advantages: Avoid reference sharing, method reuse.

Disadvantages: The parent class constructor will be called twice, which slightly affects performance.

Original type inheritance

based on Object.create()Creates a new object as a prototype.

Advantage: Simple way to implement inheritance.

Disadvantages: Cannot implement constructor parameter transfer.

Parasitic inheritance

based on the original style inheritance, the creation of objects based on enhanced functionality.

Parasitic combination inheritance

optimize combination inheritance to avoid calling the parent constructor twice.

This is the optimal scheme inherited in es5.

ES6 class inheritance

use class and extends keyword syntax, the underlying is still prototype chain inheritance.

Syntax is simple, easy to read, and supports super call.

Interview answer demonstration

question: What are the inheritance methods in JavaScript? What’s the difference between them?

Example answer:

“Inheritance in JavaScript mainly includes prototype chain inheritance, borrowing constructor inheritance, combination inheritance, original type inheritance, parasitic inheritance, parasitic combination inheritance and ES6 class inheritance. Prototype chain inheritance is simple but will lead to the problem of reference type sharing. Borrowing constructor inheritance can solve the sharing problem but the method cannot be reused. Combined inheritance combines the advantages of both but calls the parent constructor twice. Parasitic combined inheritance optimizes the number of combined inheritance calls. ES6 class inheritance syntax is simpler and more powerful.”

summary

understanding the principles and advantages and disadvantages of various inheritance methods helps to choose the most appropriate inheritance scheme to deal with different business scenarios. The ES6 syntax greatly simplifies the writing and understanding of inheritance, but the underlying mechanism is still the prototype chain mechanism. Familiarity with traditional inheritance can also help us better understand JavaScript’s object model.
