Summary

React component must declare import React from 'react '; is determined by the JSX compilation mechanism. Although JSX looks like HTML, it is actually a kind of syntactic sugar and ultimately depends on React.createElement implement Virtual DOM build. This mechanism makes React available in the scope.

With the automatic JSX conversion mechanism introduced by React 17, developers can no longer explicitly import React this facilitates the simplification of the component structure. But it also requires us to understand the version differences and configuration requirements of the toolchain.

Understanding this process will not only help us write more correct React code, but also be more leisurely in building tools or framework customization.
