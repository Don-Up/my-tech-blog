Understanding for…of, for…in and for loops in JavaScript

foreword

traversal is an important means of manipulating data structures in JavaScript, and for , for...in and for...of although the three loop syntax is similar on the surface, there are great differences in actual use. Understanding their similarities and differences is the basis for writing high-quality front-end code, and is often examined in many front-end interviews.

Text

first, for loop: the foundation of the Foundation

for it is the most basic loop syntax, which relies on indexes for control and is suitable for data structures with length properties such as arrays and strings. Its grammatical form is as follows:

this method has high execution efficiency and strong controllability, and is suitable for scenarios that need to manually control the index or interrupt the loop halfway. However, it is not suitable for traversing objects, because objects do not have the concept of “subscript.

Second, for…in: used to traverse object properties

for...in is a syntax designed to traverse the object itself and the enumerable properties on the prototype chain. For objects, not recommend for arrays.

Need to pay attention to a few points:

  • it enumerates the properties inherited from the prototype chain
  • the order of properties is not guaranteed
  • If used in an array, may traverse to non-numeric indexes or custom properties

therefore for...in more suitable for traversing the keys of the object.

Third, for…of: used to traverse iterable objects

for...of is a new syntax introduced by ES6 for traversing [Symbol.iterator] interface, such as array, string, Set, Map, arguments, NodeList, and so on.

Compared for , which masks the details of the index; for...in , it only focuses on “values”, not “keys”.

Not available directly to ordinary objects unless iterator methods are explicitly defined for the object.

Interview answer

Question: Please tell us the difference between for, for…in and for…of, which scenarios are applicable?

Answer demonstration:

these three loop syntax in the traversal structure of each applicable scenario. for is the most primitive way, suitable for the need to manually control the index, such as the array of partial traversal or reverse traversal. for…in is more suitable for object property traversal, which enumerates the object itself and inherited enumerable properties, but is not suitable for arrays, because it may traverse unexpected keys. for…of is used to traverse iterable objects. It automatically skips prototype attributes and does not contain manually added attributes. It is more suitable for arrays, Set, Map and other structures. If you are traversing the values in an array, you recommend use for…of; If key-value pairs are required, forEach or entries of Map with for…of is a more appropriate way.

Summary

the differences between the three loop syntaxes are reflected in semantics, applicable data structures, and behavioral details. Understanding the mechanisms behind them will not only help you write more robust code, but also help you choose the right traversal strategy for complex projects. If you are asked about this part of the interview, in addition to clearly explaining the grammar and scene, you can also add some details of your application in the actual project to make your answer more convincing.
