Whether object.de fineproperty can listen to intercept array changes

foreword

in front-end development, arrays are one of the most commonly used data structures. Listening for changes to arrays is important, especially when building responsive systems. In JavaScript, Object.defineProperty was an early means of implementing reactive data, but it had limited support for arrays. This paper will analyze Object.defineProperty whether it can listen for and intercept array changes, and explain its limitations and solutions.

Limitations of object.de fineproperty on array listening

listens for access and assignment of array elements

Object.defineProperty the ability to define a separate getter and setter on the index element of an array to listen for accesses and assignments to that element. But this has the following problems:

  • the length of the array may change dynamically, the index will continue to increase, the new index must be dynamically defined listening, maintenance is complex.
  • It is not possible to intercept the behavior of an array that is changed by a method, such push , pop , splice wait.

Unable to listen for calls to array methods

Changes to arrays are mostly done through built-in methods, such push , pop , shift , splice wait. Object.defineProperty you cannot listen to these method calls directly, so you cannot catch array changes caused by the method.

High implementation complexity and high performance overhead

in order to listen to all indexes, you need to dynamically add getters/setters for each new element, which is costly to maintain and perform as the array grows.

Vue 2 Responsive Solution to Array

Vue 2 is used in the reactive implementation. Object.defineProperty , the change monitoring of the array is mainly implemented by the “rewrite” array prototype method. Specific practices are:

  • copy the array prototype method, change the method (e. G. push ) to rewrite and inject the logic to notify the update.
  • Getters/setters are also defined for array index elements, listening for access and assignment.

This scheme makes up Object.definePropertyInadequacy of not being able to directly listen to array method calls.

Interview answer demonstration

q: “Can object.de fineproperty listen to intercept array changes? Please explain why.”

“ Object.defineProperty you can define getters and setters for each index of the array to listen to the access and assignment of elements, but you cannot directly listen to the method calls of the array, such. push , pop , splice wait. Because these methods operate on the internal state of the array, they do not trigger property accesses.

In Vue 2, in order to make up for this defect, we will rewrite these change methods, inject responsive logic, and combine getter/setter to monitor array changes.

Overall, Object.defineProperty the array monitoring is limited, the maintenance is complex, and the performance overhead is high. However, es6’s Proxy can intercept all operations including array methods, which is a more perfect solution.”

summary

Object.defineProperty it is not possible to fully listen to array changes, especially the call of array methods. However, this problem can be partially solved by overriding the array change method. In contrast, ES6Proxy provides a more comprehensive array listening capability, can directly intercept all operations, is a more ideal choice.
