The execution process of the render stage

Foreword

the rendering process of React is subdivided into multiple phases under the Fiber architecture, of which the render phase (also known as the coordination phase) is one of the core phases. It is responsible for comparing the old and new Virtual DOM, building a new Fiber tree, and preparing the change information that needs to be updated, but it does not directly modify the real DOM at this stage.

This article will analyze the execution process of the render phase in detail, including key steps such as task splitting, traversal sequence, status update, Diff calculation, etc., to help readers understand how React efficiently completes rendering preparations.

Core objectives of the render phase

the primary responsibilities of the render phase are:

  • constructs a new Fiber tree representing the latest UI state.
  • Compare the old and new Fiber nodes to find out the parts that need to be inserted, updated and deleted.
  • Generate a side Effect List to record all changes.
  • Prepare all change data required for the commit phase.

It is worth noting that the render phase does not operate the real DOM, which is a pure calculation process and supports interruptable and scheduling.

The execution process of the render phase

1. Start with the root Fiber

the rendering task starts at the root Fiber node and enters the coordination process. The root node represents the portal of the entire application.

2. Depth-first traversal of the Fiber tree.

React uses a depth-first traversal strategybeginWork and completeWork two processes, one by one Fiber node to complete the coordination.

  • beginWork : Computes the new state and child nodes of the current node, and builds or reuses the child Fiber.
  • completeWork : Complete the coordination of the current node and prepare the side effect chain.

3. Unit task split

each Fiber node represents a unit task. The render phase splits the task into multiple small units and executes them sequentially. After a unit task is completed, scheduling can be suspended to achieve time slicing.

4. Diff calculation

compare the types and attributes of the old and new Fiber nodes, and mark the parts that need to be updated. Different types of nodes are replaced directly, and nodes of the same type update attributes and recursively Diff child nodes.

5. Side-effect chain list construction.

During the coordination process, side effects, such as insert, delete, and update, are collected to form an Effect List for batch execution in the subsequent submission phase.

Status updates in the render phase

the render phase is also responsible for handling status updates (e. G. setStateCall), merge the update queue, calculate the latest state, and reflect it on the new Fiber node.

Difference between render phase and commit phase

the render phase is the core of the coordination phase, which is responsible for preparation and supports suspension and recovery. The commit phase synchronously executes changes and updates the real DOM and life cycle.

Interview answer example

question: Please briefly describe the execution process of The React render phase.

Example answer:

the render phase starts from the root Fiber node and adopts a depth-first traversal strategy to execute beginWork and completeWork to build a new Fiber tree. It compares the old and new Fiber, calculates the difference, and generates a list of side effects of the change.

This phase splits the rendering task into multiple units to support interruptible execution and avoid long-term blocking of the main thread. The status update is merged into the Fiber, and the updated data is finally ready for the commit phase.

Summary

the React render phase is a key part of the rendering process. It is responsible for building a new Fiber tree through depth-first traversal, completing Diff calculations, and collecting side effects. It supports task splitting and interruptible execution, ensuring that the update process is both efficient and responsive.

In-depth understanding of the execution mechanism of the render phase helps developers to optimize performance and debug complex rendering issues, improving the overall quality of React applications.
