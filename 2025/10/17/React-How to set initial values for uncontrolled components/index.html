How to set initial values for uncontrolled components

Foreword

in React, components can be divided controlled Components and uncontrolled components . The former manages the component value by the state of React, while the latter manages its own state directly through the DOM element. Uncontrolled components are usually ref reference to access the DOM, rather than relying on React’s data stream.

While React is more recommend to use controlled components to maintain consistent data flow control, it is often more natural and efficient to use uncontrolled components when working with forms, file input, performance optimization, or integration with third-party libraries. In this scenario, there is a common problem:

“How do I set an initial value for an uncontrolled component?”

this article will focus on this issue, from the principle of speaking, and through the code example of a comprehensive analysis of the setting and considerations.

This defaultValue it only takes effect when the component is first rendered and is not updated with changes in props or state.

Summary

Unmanaged components provide React with a flexible means of manipulating the native DOM, especially when working with forms. Although React advocates state-driven, uncontrolled components have unique advantages in terms of performance, code complexity, file input, and so on.

When setting the initial value, simply use defaultValue or defaultChecked that is, they are written to the DOM after the first rendering and will not be controlled by React again. By ref getting the current value and completing the business logic with event processing is the standard pattern for using uncontrolled components.

Mastering this knowledge can help you write more flexible and well-performing React form components.
