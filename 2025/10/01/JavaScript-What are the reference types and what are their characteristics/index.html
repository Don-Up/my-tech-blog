What are the reference types and what are their characteristics

Foreword

in JavaScript, reference types are an important part of variable storage and passing, and understanding them is critical to mastering memory management and data manipulation. The reference type is different from the value type, and the operation is more of a reference to the memory address. This article will systematically explain the common reference types in JavaScript and their core characteristics.

Reference Types in JavaScript

reference types are essentially objects. They include:

  • ordinary Object
  • Array (Array)
  • Function (Function)
  • Date Object (Date)
  • regular Expression Object (RegExp)
  • new ES6 data structures such as Map, Set, WeakMap, and WeakSet
  • user-defined object

these types are objects and have properties and methods.

Core features of reference types

  1. storage mode
    reference type variables store the address (reference) of the object in heap memory, not the value of the object itself.
  2. Variability
    reference types are mutable. Even if the variable is a constant (const) declaration, internal object properties can still be modified.
  3. Assignment is a copy reference
    The assignment operation copies the memory address, multiple variables point to the same object, and any modification will be reflected in all variables that refer to the object.
  4. Function parameter passing is to pass the reference address.
    When a reference type is passed in as a function parameter, the reference address of the object is passed, and the content of the object can be modified inside the function, and changes can be observed outside.
  5. Has a prototype chain
    reference types inherit from Object.prototype has a prototype chain that supports inheritance and method sharing.

Reference Types and Garbage Collection

because reference types occupy heap memory, the JavaScript engine uses a garbage collection mechanism to reclaim objects that are no longer referenced to avoid memory leaks.

Example Description

details that need attention

  • reference types can produce new copies of objects through shallow or deep copies, avoiding direct sharing of references.
  • Functions are special objects that can be called to execute.
  • null is a special value type, not a reference type.

Interview answer demonstration

question: What are the reference types in JavaScript and what are their characteristics?

Example answer:

“The reference types in JavaScript are basically objects, including ordinary objects, arrays, functions, dates, regular expressions, and ES6 Map, Set, etc. They store the reference address of the object in heap memory, not the actual value. The reference type is variable, the reference address is copied when assigning, multiple variables will point to the same object, and modifying one of the variables will affect the other variables. When a function passes a parameter, it passes a reference to the object, and internal changes to the function are reflected to the outside. Reference types have prototype chains to support inheritance and sharing methods, and memory management is handled automatically by the garbage collection mechanism.”

summary

mastering the types and characteristics of reference types helps to understand the memory model and data manipulation behavior of JavaScript. Reasonable use of reference types, combined with copy technology, can effectively avoid data pollution and potential performance problems, improve the robustness of the code.
