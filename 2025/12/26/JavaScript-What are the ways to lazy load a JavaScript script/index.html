What are the ways to lazy load a JavaScript script

Foreword

in modern Web development, optimizing page load performance is critical. Reasonable delay loading of JavaScript scripts can reduce the first screen loading time and improve user experience. This article will systematically introduce a variety of common JS script delay loading methods, principles and applicable scenarios to help you design high-performance front-end loading strategies.

Common JavaScript lazy loading methods

1. Use defer property

will <script>of the label defer property is set to true, the browser will download the script asynchronously, but the script execution will be delayed until the HTML parsing is completed, and the execution order is the same as the order of appearance.

Suitable for all DOM-dependent scripts.

2. Use async property

async property causes the script to be downloaded asynchronously and executed immediately after the download is complete, the order of execution is not guaranteed, and may be earlier or later than DOM resolution completes.

Suitable for scripts that do not rely on DOM and are independent of each other.

3. Dynamically create script tags.

Dynamically created via JavaScript scriptTag and insert the DOM, and the script is loaded and executed asynchronously.

Suitable for loading function modules on demand.

4. Use a module loader (e. G. RequireJS, Webpack dynamic import)

modern module Packer support dynamic import module, load on demand, reduce the initial load volume.

Supports code splitting and lazy loading.

5. Delay execution of scripts

binding setTimeout and other mechanisms to delay the insertion or execution of scripts to reduce the first screen blocking.

6. Use the Intersection Observer to load the script lazily.

Combined with whether the element enters the viewport, determine when to load the relevant script to achieve on-demand loading.

Comparison of applicable scenarios in various ways

  • defer suitable for all scripts that rely on DOM, good compatibility.
  • async suitable for third-party statistics, advertising and other scripts that do not rely on the order.
  • Dynamic loading is suitable for lazy loading of functional modules to improve performance.
  • Module dynamic import is suitable for modern projects to achieve code segmentation.
  • Delayed execution is suitable for non-critical scripts to delay loading.
  • Intersection Observer is suitable for dynamically loading resources based on user scrolling behavior.

Interview answer demonstration

Q: “What are the common JavaScript lazy loading methods? What scenes are suitable for each?”

“JavaScript script delay loading mainly in the following ways:

first, give <script> tag Add defer property, allowing scripts to be executed in sequence after HTML parsing, suitable for scripts that depend on DOM.

Second, use async property, the script is loaded asynchronously and executed immediately after the download is completed, suitable for independent scripts that do not depend on the order.

Third, dynamically create script tags to load on demand and flexibly control the loading timing.

Fourth, modern modular tools support dynamic import, code segmentation and lazy loading.

In addition, timers or Intersection observers can be used to delay execution or lazy loading to improve performance.

Choose the right way to ensure fast page rendering and interactive response based on Script dependencies and performance requirements.”

summary

rational Utilization defer , async dynamic loading and modular dynamic import can effectively delay the loading and execution of JavaScript scripts, reduce the loading pressure of the first screen, and improve the user experience. Understanding their principles and differences helps to design efficient front-end loading schemes.
