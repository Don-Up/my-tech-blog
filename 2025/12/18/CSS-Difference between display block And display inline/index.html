Difference between display block And display inline

foreword

display: block and display: inline are the two most commonly used element display types in CSS, and understanding their differences is the basis for understanding the layout of a web page. There are obvious differences between the two in terms of space occupied by elements, layout rules, and box model applications, which have a profound impact on the page structure and visual effects.

Features of display: block

set block the elements of are represented as block-level elements. They will occupy one row exclusively, the width will fill the available width of the parent container by default, and the height will be determined by the content. Block-level elements can set width and height, upper and lower outer margins, and inner margins, which will trigger line wrapping, and there will be outer margin folding between upper and lower adjacent block elements.

Typical block-level elements are <div>, <p>, <h1>wait. Block-level elements are suitable for building page structure and layout containers.

Features of display: inline

set inlineThe elements of are represented as in-line elements. They will not occupy a single line, the width is determined by the content, the width and height cannot be set directly, only the left and right inside and outside margins can be set. The in-line elements are arranged in a row, and the text content is wrapped in it.

Common in-line elements are <span>, <a>, <em>wait. Inline elements are suitable for local style adjustment of some content in the text.

Summary of key differences

first of all, block the element wraps and takes up the full line width, inline the element does not wrap, and the width is determined by the content. Secondly, block element can set the width and height, inline elements cannot be set to width and height. Third, block the upper and lower outer margins of the element are valid, inline the upper and lower margins of an element are generally invalid, and only the left and right margins can be set.

These differences determine the different scenarios they apply to, and fair use can build a clear and flexible page structure.

Interview answer

display: blockMake the element appear as a block-level element, occupying a whole row, you can set the width and height of the upper and lower margins, suitable for layout containers; display: inline make the element appear as an in-line element without line wrapping, the width is determined by the content, the width cannot be set, the upper and lower margins are invalid, and it is suitable for local styles in the text. The main difference between the two is the layout behavior and the application of the box model.

Summary

understanding block and inline the difference is the basis of the front-end layout. By reasonably switching between these two display types, complex and flexible page layout and style control can be realized, providing users with a good visual and interactive experience.
