The role of the Arrow function

arrow function mainly has the following functions and characteristics:

  • the syntax is concise, omitting function keyword, suitable for writing short function expressions.
  • Not binding your own this , this inherited from the outer context, lexically scoped binding.
  • Not bound arguments object, if you need to access the outer arguments , you can directly use the outer function’s arguments .
  • Cannot be used as a constructor, cannot be used new call.
  • Do not haveprototype property.
  • Cannot be used yield and therefore cannot be a Generator function.
