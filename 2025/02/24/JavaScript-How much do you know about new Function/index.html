How much do you know about new Function

Foreword

JavaScript provides a variety of ways to define and execute code, among which new Function constructors are a mechanism for dynamically creating functions. It differs from regular function declarations or function expressions in that it has unique behavior and usage scenarios. Understanding new Function the principles, advantages, and risks of are essential for writing safe and efficient dynamic code. This article will detail new Function usage and precautions.

new Function allows you to pass in several parameter names, the last parameter is a string of the function body.

Difference between new Function and ordinary Function

  • different execution environment
    new Function the created function executes in the global scope and does not close the variables in the external scope.
  • Code dynamic parsing
    the function body string is parsed dynamically when it is called, similar evalThere is a security risk.
  • Scope Isolation
    you cannot access the context scope in which it was created, only global variables and its own parameters.
  • Performance overhead
    the dynamic compilation string is a function, which is expensive, and frequent calls will affect performance.

Use Scenario

  • dynamically generate code, such as a calculation function based on a string.
  • When you need to dynamically construct complex function logic from a string.
  • In a metaprogramming tool or script engine.

Risks and Considerations

  • security risk
    dynamic execution of string code is prone to injection attacks, especially when generating function bodies from untrusted data.
  • Difficulty in debugging
    the generated function has no file name and line number, and the debugging experience is poor.
  • Performance issues
    dynamic parsing consumes a lot. We recommend that you cache the generated functions.
  • Cannot access closure variable
    the outer function variable that defines it cannot be accessed, limiting usage scenarios.

Example

alternatives

  • use ordinary functions and closures to dynamically create logic to ensure safety and performance.
  • Avoid using new Function dynamic execution of untrusted code.

summary

new Function provides powerful dynamic function generation capabilities, but also brings security, performance, and debugging challenges. It is generally recommended to avoid frequent use in production environments unless you explicitly need to dynamically compile and execute code. Mastering its principles and limitations is helpful to make reasonable use of it in specific scenarios and improve code security and maintainability.
