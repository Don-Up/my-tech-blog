Basic Commands

  • hexo init - Initialize a new Hexo site
  • hexo new [layout] <title> - Create a new post/page
  • hexo generate or hexo g - Generate static files
  • hexo server or hexo s - Start local server for preview
  • hexo deploy or hexo d - Deploy website

Generation Options

  • hexo generate --watch or hexo g -w - Watch file changes and regenerate automatically
  • hexo generate --deploy or hexo g -d - Generate and deploy after completion

Server Options

  • hexo server -p <port> - Start server on specific port
  • hexo server -i <ip> - Start server on specific IP address

Deployment

  • hexo deploy --generate or hexo d -g - Generate and deploy website

Cleaning

  • hexo clean - Clean cache and generated files

Publishing

  • hexo publish [layout] <filename> - Publish a draft

Useful Combinations

  • hexo clean && hexo g -d - Clean and then generate/deploy
  • hexo new draft "title" - Create a new draft post

These commands help manage your Hexo blog workflow from creation to deployment.
