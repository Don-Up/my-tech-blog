How to achieve code splitting and lazy loading for routing

Foreword

in modern front-end development, the application volume is getting larger and larger, and the loading speed of the first screen has become one of the key factors affecting the user experience. To improve performance, Code Splitting and Lazy Loading techniques are widely used. React combines routing to implement code segmentation and lazy loading, which can dynamically load the corresponding page code according to the user’s actual access path, avoid loading all resources at one time, and significantly improve the application loading efficiency.

This article will combine React Router to introduce in detail how to implement code segmentation and lazy loading at the routing level, analyze its principles and specific implementation methods, and give sample code to help understand.

what is Code splitting and lazy loading?

Code segmentation is to split the application code into multiple independent code blocks (chunks) and load them on demand, thus avoiding packaging into a bulky file.

Lazy loading is to load a part of the code when it is really needed, rather than loading it all at initialization.

The combination of the two can effectively reduce the size of the first screen package and improve performance and user experience.

how does React realize routing code segmentation and lazy loading?

React is officially provided. React.lazy and Suspense component to implement lazy loading of code. Combined with React Router, you can Lazily load the components corresponding to the route.

Principle Analysis

  • React.lazy Internal Use Dynamic Import import() , Webpack generates independent code blocks based on this syntax.
  • When a route is accessed, the request of the corresponding module is triggered.
  • Suspense monitor the loading status of the lazy loading component, render the fallback content when the component is not loaded, and render the real component after the load is successful.

Optimization Suggestions and Advanced

  1. refine Route Split
    different routes can be split into multiple lazy load components according to business scenarios to reduce the size of each block.
  2. Preload/Prefetch
    magic annotation using Webpack /* webpackPrefetch: true */ preload the routing resource to be accessed.
  3. Error boundary handling
    loading failures may occur during lazy loading, and The React error boundary component captures exceptions to provide user-friendly prompts.
  4. Lazy loading of nested routes
    lazy loading can also be used for nested routing components to further optimize performance for large applications.
