What are the traversal methods of objects

foreword

in JavaScript, objects are very common data structures that store data in the form of key-value pairs. Many times, we need to traverse the properties of an object to perform operations, such as statistics, filtering information, or generating new structures. Understanding how objects are traversed is important for writing efficient, clear code. This article will detail several common object traversal methods in JavaScript, analyze their applicable scenarios and points for attention, and help you make the right choices in development.

Text explanation

JavaScript Object traversal mainly has the following several ways:

  1. for…in loop
    this is the most traditional way of traversing objects. It traverses all the enumerable properties of the object itself and inherited (including those on the prototype chain). It should be noted that for…in traverses the key name string, and the order is not necessarily the insertion order.

Usually need to use hasOwnProperty filter out inherited properties to ensure that only the properties of the object itself are manipulated.

  1. Object.keys() method
    it returns an array containing the key names of all the enumerable properties of the object itself, excluding inherited properties. Using the returned array, you can use array methods to traverse (such as forEach, map, etc.), and the traversal order adds the order to the property.
  1. Object.values() method
    similar to Object.keys, but returns an array of values corresponding to all enumerable attributes of the Object itself.
  1. Object.entries() method
    it returns a two-dimensional array where each element of the array is represented [key, value] the array that consists. It can be used to deconstruct key-value pairs, which is very convenient for traversing.
  1. Reflect.ownKeys() method
    this method returns all the key names of the Object itself (including non-enumerable and symbolic properties), which is more comprehensive than Object.keys. Usually used to do unified operations on all attributes.
  1. for…of Object.entries()
    although the Object itself cannot be traversed directly with for…of, a more concise and elegant key-value pair traversal can be achieved by combining Object.entries.

Comparison and selection of various traversal methods

  • if you need to traverse all enumerable properties of the object (including inherited properties), use for…in, but it is not recommend to use it directly in general development, which is prone to prototype chain property interference.
  • If you want to traverse its own properties and ensure the order, Object.keys is the first choice.
  • If you only need values, Object.values is handy.
  • Object.entries is the most intuitive when both keys and values are required.
  • Reflect.ownKeys is more appropriate when you need to include non-enumerable or symbolic properties.

Interview answer demonstration

The interviewer asked, “What are the ways of traversing objects in JavaScript? What are their respective characteristics and usage scenarios?”

“JavaScript Object traversal mainly has several common ways. The first is for...in loop, which traverses all enumerable properties on the object and its prototype chain, but because it may traverse inherited properties, it is usually used in conjunction hasOwnProperty filtration. The second is Object.keys() , which returns the key array of all enumerable properties of the object itself. The traversal order is the same as the property addition order, which is very suitable for scenarios where the order needs to be guaranteed. Furthermore, it is Object.values() , which returns an array of values, suitable for situations where only values are required. Object.entries() returns an array of key-value pairs, combined for...of when used, the writing is concise and clear, suitable for scenes that need keys and values at the same time. If the item involves symbolic or non-enumerable properties, you can use Reflect.ownKeys() to get all types of keys.

In actual development, I generally prefer Object.keys() combine the array traversal method because it is both concise and safe. for...inIt is now used less often, unless you specifically need to traverse inherited properties. In the case of particularly high performance requirements, a more suitable method will be selected according to the actual situation.”

summary

object traversal is a very basic and common operation in front-end development. Mastering different traversal methods and their characteristics will allow you to write more robust and better-performing code. for...in it is the most primitive traversal method, but it should be used with caution due to its traversal of the prototype chain. Object.keys , Object.values and Object.entries it is the mainstream choice of modern development, which can more clearly control the properties of the traversal object itself, and the order can be controlled. Reflect.ownKeys the traversal range is extended to suit special needs. Choosing the appropriate traversal method according to specific business requirements is an important part of improving code quality.
