Each time a function component is rendered, a new function is created

Foreword

in The React function component, the functions defined within the component are recreated each time the component renders. Although this behavior conforms to the function execution mechanism of JavaScript, when these functions are passed as props of subcomponents, it is easy for subcomponents to receive new function references, thus triggering unnecessary re-rendering and affecting performance.

This article will analyze in detail the problems caused by the creation of new functions in function components, explain why this leads to repeated rendering of subcomponents, and introduce a variety of effective optimization methods to help developers control function references reasonably and avoid unnecessary subcomponent rendering.

Background and essence of the problem

in React, the function component is essentially a common JavaScript function. Every time the parent component is rendered, the function component is re-called, all variables (including functions) inside the component are re-defined, and the function naturally becomes a new reference.

When this new function is passed to the child component as a prop, even if the function logic remains unchanged, the child component will think that the props has changed due to the different references, resulting in a re-rendering.

why changes in function references cause repeated rendering of subcomponents

React in React.memo or PureComponent use shallow comparison to determine whether props changes. The function is a reference type. The shallow comparison only compares the reference address. The old and new addresses of the function are different and are considered to have changed.

Therefore, even if the function body is the same, the reference change will be judged as a new props, causing the subcomponent to update.

avoid passing new functions to cause repeated rendering of sub-components.

V. Summary

The function component re-creates the internal function every time it renders, which causes the reference to change when the function is passed as props, which in turn triggers the child component to re-render. The key to avoiding this problem is to ensure that the function reference passed to the child component is stable. The most common method is to use useCallback caching function references while avoiding direct inline function definitions in JSX. Cooperation React.memo use, you can effectively improve component rendering performance and avoid unnecessary redrawing.
