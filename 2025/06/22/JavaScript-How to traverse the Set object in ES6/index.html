How to traverse the Set object in ES6

foreword

Set is a new data structure introduced by ES6 to store unique values. Unlike arrays, sets do not allow repeating elements, which makes them useful in scenarios such as deduplication and Set operations. Mastering the traversal method of Set will help you process and manipulate collection data efficiently. This article will systematically introduce the various traversal methods of Set objects and their applications.

Common Methods and Characteristics of Set Traversal

Set maintains the order in which elements are inserted, and all traversal methods output elements in the order they are added. Common traversal methods are:

  1. for…of loop
    the Set object itself is iterable, traversing all elements directly with a for…of loop.
  1. Set.prototype.forEach() method
    Set also provides the forEach method, and the callback function receives three parameters: the current value, the current value (the same value twice, in order to be consistent with Map), and Set itself.

It should be noted that the first two parameters of forEach are the same, which is a design consistency (maintaining the same parameter structure as Map’s forEach), although it is not necessary for Set.

  1. values() and keys() methods
    set. values() and keys()Method returns the same iterator, iterating over the elements. Because Set has no keys, the keys and values methods behave the same.
  1. entries() method
    set. entries() method returns a [value, value] the iterator is also designed to be consistent with the Map interface.

This design, while somewhat redundant, ensures the uniformity of the traversal interface.

Choose the appropriate traversal method

  • in most cases, use directly. for...of traversal Set, simple and clear.
  • When you need a more functional way of writing, forEach also very convenient, especially suitable for chaining or callback logic.
  • values() , keys() and entries() more is to unify the interface, the general use is not much.
