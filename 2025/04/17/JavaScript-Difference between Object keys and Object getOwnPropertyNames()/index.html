Difference between Object keys and Object getOwnPropertyNames()

foreword

in JavaScript, getting the list of properties of an object is a common requirement in development. Object.keys and Object.getOwnPropertyNames() both can get the properties of an object, but there are subtle differences between them, and understanding these differences can help you choose and use them correctly and avoid potential errors. This article will analyze the differences and applicable scenarios in detail.

The main difference between the two

1. The types of properties returned are different.

  • Object.keys(obj) returns an array of enumerable (enumerable) string keys for the object itself (without the prototype chain).
  • Object.getOwnPropertyNames(obj) returns all the properties of the object itself (including non-enumerable properties), but only the string key names, excluding the Symbol type properties.

2. Whether it contains non-enumerable properties.

  • Object.keys contains only enumerable properties.
  • Object.getOwnPropertyNames contains all self properties, whether enumerable or not.

3. Whether the Symbol property is included.

Neither contains a property of type Symbol. If you need to get the Symbol attribute, you should use Object.getOwnPropertySymbols() .

Use Scenario Recommendations

  • scenarios that need to traverse object properties (such as for…in loops), typically use Object.keys because it only returns enumerable properties.
  • Scenarios that need to get all the object’s own properties (including non-enumerable), use Object.getOwnPropertyNames .

Interview answer demonstration

q: “What is the difference between Object.keys and Object.getOwnPropertyNames?”

“ Object.keys returns an array of enumerable string properties of the object itself, suitable for regular traversal; AndObject.getOwnPropertyNames returns all string properties of the object itself, including non-enumerable properties. Neither contains inherited properties and Symbol properties. If you want to get all your own properties (including non-enumerable), the latter is more appropriate.”

summary

Object.keys with Object.getOwnPropertyNames both are powerful tools for obtaining object properties, the difference being whether they contain non-enumerable properties. Choosing the right method helps to manipulate object properties accurately and avoid omissions or errors.
