Components of a full domain name

Foreword

In the daily Web development, operation and maintenance, system deployment or Web browsing process, we often come into contact with the concept of “domain name. Whether it’s www.google.com , or api.dev.example.co.uk they are complete domain names. But these seemingly simple strings actually contain strict structure and specifications.

Understanding the composition of a complete domain name not only helps us to deepen our understanding of the Internet naming system, but also provides us with basic knowledge in configuring DNS, SSL certificates, cross-domain policies, subdomain division, CDN routing, etc.

This article will explain in detail the structure of the complete domain name and the meaning of each part, and help you fully understand this basic but key network concept through tables and examples.

What is a full domain name (FQDN)?

The full English name of the full domain name is Fully Qualified Domain Name (FQDN) the full path name that uniquely identifies a host or service in the DNS naming system. It starts with the most specific subdomain and continues to the top-level domain name (TLD), with an English period in the middle. . Separation.

The hierarchy of the complete domain name

A typical complete domain name structure is as follows:

the structural hierarchy from right to left is shown in the following table:

domain Part name description
. Root Domain (Root) the top-level DNS layer is generally not written by the user, but exists in the DNS system.
com top Level Domain (TLD) top-level classification domain, such as com, org, net, cn, etc.
example primary domain (SLD) typically a registered domain name that uniquely identifies an organization, company, or individual
www Subdomain customized by the primary domain owner, such as www, api, blog, m.admin, etc.
host1 (Optional) Host name (Hostname) used in some cases to identify a machine more specifically, such host1.www.example.com.

Example parsing:

  • full domain name: www. Blog. Example. Co. Uk.
  • Root Domain: . (Omit not to write)
  • top Level Domain: uk
  • primary Domain: co
  • second-level domains (registered domain names): example
  • subdomain: blog
  • subdomain/Hostname: www

in the DNS query process, the resolution is from right to left step by step, until the specific host address is found.

Summary

the full domain name (FQDN) is not a simple string, but a structured, hierarchical naming system that uniquely identifies a host or service address in the DNS system. Understanding the role of its various parts has practical value for Web development, system operation and maintenance, network configuration, etc.

Mastering the composition of FQDN helps:

  • configure DNS records correctly
  • understanding the HTTPS certificate binding relationship
  • designing a Reasonable Subdomain Structure
  • configure network policies such as reverse proxy and cross-domain access
