What are the common network protocols

Foreword

in today’s era of rapid development of the Internet, front-end development, back-end services, network communications and other fields are inseparable from the support of network protocols. Whether it’s web page loading, data requests, video playback, or file downloads, there are specific protocols behind them that coordinate communication. Understanding common network protocols not only helps to improve the debugging and optimization capabilities of developers, but also better ensures the security and reliability of the system.

This article will explain in depth the types, characteristics, and application scenarios of common network protocols, and help you build a knowledge system of network protocols from the transport layer to the application layer.

Overview of Network Protocol Layering Architecture

network communication is usually based on OSI seven-layer model or TCP/IP four-layer model . The latter is the model actually adopted by the Internet, and the protocol also revolves around these four layers:

level protocol Example main functions
application Layer HTTP, HTTPS, FTP, DNS, SMTP provide application-specific services
transport Layer TCP, UDP establish end-to-end communication to ensure data transmission
network layer IP, ICMP, ARP, IGMP handle routing and addressing, packet forwarding
Link Layer/Physical Layer ethernet, Wi-Fi, PPP physical transmission, data frame encapsulation

understanding how these protocols work together helps to systematically grasp the network communication mechanism.

Application layer protocol

HTTP(HyperText Transfer Protocol)

the most common application layer protocol, used for data transmission between the client and the server, especially Web pages, interfaces and other content.

Features:

  • based on the request-response model
  • stateless, clear text transfer (unless HTTPS is used)
  • support multiple methods such as GET, POST, PUT, DELETE

HTTPS(HTTP Secure)

is a protocol that adds the TLS/SSL encryption mechanism on top of HTTP to ensure communication security.

Features:

  • data encryption, anti-hijacking, anti-tamper
  • establish secure channel based on TLS (formerly SSL) handshake
  • it is the standard protocol for modern Web applications.

FTP(File Transfer Protocol)

protocol for file upload and download.

Features:

  • support user authentication
  • divided into control connection and data connection
  • There are active mode and passive mode

DNS(Domain Name System)

system protocol for resolving domain names to IP addresses.

Features:

  • hierarchy (root domain, top-level domain, authoritative domain)
  • common record types: A, CNAME, MX, TXT, etc.
  • Common attacks: DNS poisoning and DNS Amplification Attacks

SMTP/POP3/IMAP

for sending and receiving email:

  • SMTP: Send Mail (outgoing server)
  • POP3: Receive mail (download to local)
  • IMAP: Receive mail (keep server copy)

transport Layer Protocol

TCP(Transmission Control Protocol)

A connection-oriented transport protocol that provides reliable data transmission.

Features:

  • three handshakes, four waves
  • ensure data orderly, complete, no packet loss
  • support flow control, congestion control

applicable scenarios: file transfer, web page loading, database communication and other applications that require high reliability.

UDP(User Datagram Protocol)

connectionless transport protocol for speed and efficiency.

Features:

  • sequence not guaranteed, reliability not guaranteed
  • no handshake process, send and forget
  • it is often used in scenarios with high real-time requirements, such as voice, video, and DNS queries.

Network Layer Protocol

IP(Internet Protocol)

the core protocol of the network layer, responsible for packet addressing and routing.

Features:

  • IPv4(32-bit address) and IPv6(128-bit address)
  • no guarantee of data reliability, only responsible for delivery to target host
  • work with TCP/UDP

ICMP(Internet Control Message Protocol)

network Control Message Protocol for passing error and status information.

Common Applications: ping the command is based on ICMP and is used to test host connectivity.

ARP(Address Resolution Protocol)

address Resolution Protocol, used to resolve IP addresses to physical addresses (MAC).

Working mechanism:

  • the host broadcasts an ARP request and the target host responds with its MAC address
  • the mapping results are cached in the ARP table

link Layer and Physical Layer Protocols

Ethernet (Ethernet)

the most mainstream LAN communication protocol defines the frame structure, MAC address and so on.

Features:

  • based on CSMA/CD (conflict detection)
  • typically using twisted pair or fiber optic transmission
  • each device has a unique MAC address

PPP(Point-to-Point Protocol)

point-to-point link protocol, commonly used for dial-up or serial communication.

Schematic of the relationship between the agreements

the following is a schematic diagram of the actual protocol stack interaction for a requested web page:

  1. application layer: browser initiated HTTP GET request
  2. transport layer: TCP establishes a connection and transmits data in fragments
  3. network layer: IP location server address, routing and forwarding
  4. link layer: Ethernet frames are transmitted on the physical link

this process reflects the top-to-bottom encapsulation collaboration between protocols and also demonstrates the operation of multi-protocol composition in the request process.

Interview answer

question: Do you know the common network protocols? Can say a few and its role?

A: Common network protocols can be classified from each layer of the network model:

  • application layer protocols such as HTTP/HTTPS are used for Web communication, DNS is used for domain name resolution, and FTP is used for file transfer.
  • In the transport layer protocol, TCP provides reliable connection and UDP provides fast communication
  • network layer protocols such as IP are responsible for addressing and routing, ARP is responsible for address resolution, and ICMP is used for diagnosis.
  • Link layer such as Ethernet defines the frame format and MAC address transmission

these protocols usually work in combination. For example, HTTPS + TCP + IP + Ethernet is used when browsing web pages. Familiarity with these protocols can help us troubleshoot network problems more efficiently and design more robust system communication mechanisms.

Summary

network protocols are the cornerstone of the modern Internet, and protocols at different levels work together to reliably transmit data from the source to the destination. This paper systematically combs the common network protocols and their functions, from the application layer such as HTTP and DNS, to the transport layer such as TCP and UDP, to the IP, ARP and ICMP of the network layer, and the Ethernet of the link layer.

Understanding these protocols can not only improve the depth of technology, but also a common high-frequency topic in front-end, back-end, operation and maintenance, testing and other job interviews. It is recommended that developers pay more attention to the details of the network request, response header, status code and network link in the project, and consolidate the understanding of the protocol from the actual scene.
