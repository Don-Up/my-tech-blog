The difference between controlled and uncontrolled components

Foreword

when building forms in React, developers encounter two core concepts: Controlled Components and Uncontrolled components. These terms refer to how components process user input and how data is stored. Understanding their essential differences not only helps to develop a more flexible UI, but also improves performance and maintainability by selecting a more appropriate implementation based on the scenario.

This article will analyze in detail the definition, implementation, comparison of advantages and disadvantages, and usage scenarios of controlled and uncontrolled components to help you fully grasp the differences and application skills between the two.

What is a Controlled Component?

The controlled component is passed by the React component. state component to have full control over its input values. Every time the user modifies the input box, an event is triggered. React synchronizes the new value to the state of the component through the event handler function, and then passes the updated value to the form control again through props.

What is an Uncontrolled Component?

Uncontrolled components leave the management of input values to the DOM itself, rather than being controlled by React. React through ref to access the actual DOM node to get the value. It is more like a traditional HTML form, and the component itself does not interfere with the process of user input.

usage recommendations and scenario selection

controlled components are suitable:

  • need to dynamically verify input values
  • there is associated logic between multiple form items
  • form values need to be synchronized to other views or states in real time
  • implement advanced interactions such as automatic form saving and rollback

uncontrolled components are suitable:

  • simple form or one-time input
  • input values are not frequently externally dependent
  • file Upload (input[type = file] can only obtain the value through ref)
  • performance-sensitive scenarios, avoid frequent setState

interview answer: What is the difference between controlled and uncontrolled components?

In React, a controlled component means that its input value is controlled by the state of the component. The user inputs the state to update the state through the onChange event, and then the state drives the value of input. This approach allows form behavior to be fully controlled by React, facilitating unified management, validation, and interactive control.

The uncontrolled component manages the input state by DOM itself. React does not intervene in the change of value, but reads the value of DOM node through ref when needed. It is closer to the form behavior of native HTML.

Controlled components are suitable for scenarios that require high control over data interaction, such as dynamic form validation or linkage logic, while uncontrolled components are suitable for scenarios with simple data and limited interaction, such as file uploads or forms that collect information at one time.

Summary

controlled and uncontrolled components represent essentially two different state management strategies. In development, controlled components provide greater flexibility and control, but also bring higher code complexity; Uncontrolled components are lighter and closer to the native implementation. There are no absolute advantages and disadvantages, the key is to understand their principles and make reasonable choices according to the actual needs of the project.

Mastering the differences between the two will make you more handy when building forms and lay the foundation for a deeper understanding of React’s design philosophy.
