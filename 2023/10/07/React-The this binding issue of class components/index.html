Why do I need to bind this in a class component?

In JavaScript, when a function is called this the pointing to is determined by the calling method. Event handlers in class components are usually called as ordinary functions, rather than being bound to component instances, resulting in this pointing is missing.

Common this lost scene

Solution Comparison

1. Manual binding in the constructor.

In the constructor bind explicit binding this :

advantages: good compatibility and stable performance.

Disadvantages: lengthy code, bloated constructor.

2. Use the arrow function as a class property.

Define the method as an arrow function, the arrow function will not have its own this will bind the context at the time of definition:

advantages: concise writing, automatic binding.

Disadvantages: Support class attribute syntax such as Babel is required, which may affect performance (create functions separately per instance).

3. Use the arrow function in JSX.

Use the arrow function directly in JSX:

Pros: Simplicity, avoiding explicit binding.

Cons: New functions are created with each rendering, which can lead to performance issues and unnecessary re-rendering of subcomponents.

additional considerations

  • if you forget to bind, this will be undefined (Strict mode) or global objects, which can easily lead to errors.
  • Avoid creating functions frequently in performance-sensitive scenarios, such as a large number of list events.
  • React official recommend class attribute arrow function or constructor binding, avoid defining arrow function in render.
