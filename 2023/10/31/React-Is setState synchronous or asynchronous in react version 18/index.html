This article will focus on React 18. setState the execution feature expands, delves into the mechanism behind it, and helps you sort out this key issue through code and scenarios.

The essence of setState in React

before we understand synchronous and asynchronous, we need to be clear: setState the essence of is a entry function that triggers a state change and requests re-rendering , its execution behavior is divided into two stages:

  1. synchronous execution: Adding a change request to the status update queue
  2. asynchronous processing: React batches these changes at the right time and performs component updates.

In other words, **setState** the call to is synchronous, but the update of the state and the re-rendering of the component are done asynchronously.
