What are the differences between react.memo and useMemo

Foreword

in the process of React performance optimization, react.memo and useMemo are two tools that are often mentioned. Although they have similar names and all involve “caching” and “avoiding unnecessary calculations or rendering”, their role scenarios, implementation mechanisms, and usage methods are significantly different.

Understanding the difference between the two is of great significance for the rational use of React optimization methods and improving application performance. This article will be detailed analysis react.memo and useMemo , to help you distinguish their usage and applicable scenarios.

react.memo and useMemo definitions and functions

react.memo

react.memo is a high-level component (HOC) provided by React, which is used to perform performance optimization its core role is to realize the “Memorization” of components “. When the props of a component does not change, React skips the re-rendering of the component and reuses the last rendering result to reduce unnecessary rendering overhead.

useMemo

useMemo is a React Hook, used inside a function component cache calculation results to avoid performing expensive calculations every time you render. It receives a creation function and an array of dependencies, and only recalculates when the dependencies change, otherwise reuses the cached results.

Example of usage:

useMemo the main objective of avoid double counting to improve the internal performance of the function component.

summary

react.memo it is a “memory” Optimization of components, mainly used to avoid re-rendering of function components when props does not change, and improve rendering performance. It is a performance optimization tool at the component level. useMemoIt is a performance optimization method inside the function component, which caches the calculation results to avoid repeating complex calculations or generating new objects, thereby reducing unnecessary rendering triggers. The two scenarios are different, but they are often used together to improve the performance of React applications.

Interview answer

react.memo it is a high-level component provided by React to cache component rendering results to avoid repeating rendering components when props is unchanged and improve rendering performance; useMemo is a Hook, which is used to cache the calculation results inside the function component to avoid performing expensive calculations every time it is rendered.

To put it simply, react.memo optimized is the component rendering level, useMemo the optimization is to compute the cache level. The two are often used in combination to help reduce performance loss at different levels.
