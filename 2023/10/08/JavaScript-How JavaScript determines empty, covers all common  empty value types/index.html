Common Null Type Classification

in JavaScript, we usually think of the following values as “empty:

  • undefined : undefined value
  • null : Null value (explicitly null)
  • '' (Empty string): a string of length 0
  • [] (Empty array): Array length is 0
  • {} (Empty object): an object with no own attributes
  • 0 (Numeric Zero): Null for numeric type”
  • NaN illegal Numbers
  • false : Boolean “false value”
  • new Set() / new Map() A collection or mapping with no elements
