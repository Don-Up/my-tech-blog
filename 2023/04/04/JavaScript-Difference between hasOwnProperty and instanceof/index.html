Difference between hasOwnProperty and instanceof

foreword

the need to determine object properties and object types is very common in JavaScript. hasOwnProperty and instanceof they are two concepts that are often mentioned. Although they both involve objects, their effects and mechanisms are completely different. This article will elaborate on the differences between the two methods and application scenarios to help you use them correctly.

The function and principle of hasOwnProperty

hasOwnProperty is that all objects inherit from Object.prototype to determine whether a property is a property of the object itself, rather than a property inherited from the prototype chain.

it is often used to avoid misjudging the existence of a property because of the property on the prototype chain.

The role and principle of instanceof

instanceof is to determine whether an object is an instance of a constructor. It does this by checking for the existence of a constructor in the object’s prototype chain. prototype attributes to judge.

Example:

instanceofThe focus is on the type relationships of objects, not the attributes.

The core difference between the two

  • hasOwnProperty used to determine whether the property belongs to the object itself, regardless of the type.
  • instanceof used to determine whether the type of an object inherits from the prototype of a constructor.

Take a metaphor, hasOwnProperty it is to see if the object “has this thing of its own”, and instanceof it is to see what kind of object it is “.

Applicable Scenarios

  • use hasOwnProperty detecting whether an object directly owns a property to avoid reading inherited properties. It is common to filter inherited properties when traversing object properties.
  • Use instanceof determine the construction type of an object, commonly used for type determination and instance detection.

Summary

hasOwnProperty and instanceof the concerns are different, one concerns the attribute belongs to and one concerns the object type. Understanding their differences helps to accurately manipulate objects and determine types.

To put it simply, hasOwnProperty used for Attribute level judgment, instanceof used for type level judgment, the two uses and functions are completely different.”

summary

clearly distinguish between attribute judgment and type judgment, reasonable use hasOwnProperty and instanceof , you can avoid code logic errors and improve the robustness of the program.
