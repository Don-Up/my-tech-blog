Image Component Attributes in Next.js

2023-04-13
Next.js

The Next.js <Image> component (next/image) provides several attributes that enhance performance, responsiveness, and SEO.

✅ 1. Required Attributes

Attribute Type Description
src string The image URL (local or remote).
alt string Describes the image for accessibility & SEO.
width number The image width (in pixels). (Required if fill is not used.)
height number The image height (in pixels). (Required if fill is not used.)
fill boolean Makes the image fully responsive (fills the parent container).

Example: Basic Usage

Example: Responsive Image (fill Mode)

🔹 fill removes the need for width & height and makes the image fully responsive.

✅ 2. Optional Attributes

Attribute Type Description
sizes string Defines the image size at different breakpoints (for responsive images).
priority boolean Loads the image immediately (useful for above-the-fold images).
quality number Sets image quality (1-100, default: 75).
placeholder `’blur’ ‘empty’`
blurDataURL string Custom blur placeholder image (used with placeholder="blur").
loading `’lazy’ ‘eager’`
unoptimized boolean Disables Next.js optimization (useful for special cases).

✅ 3. Example: Responsive Image with sizes

🔹 How sizes Works:

  • On mobile (≤768px), the image takes 100% (100vw) of the screen.
  • On tablets (≤1200px), it takes 50% (50vw).
  • On larger screens, it takes 33% (33vw).

✅ 4. Example: Blur Placeholder (placeholder="blur")

🔹 Why? It prevents layout shifts by showing a blurred version before the full image loads.

✅ 5. Example: High-Priority Image (priority={true})

🔹 Use priority={true} for important images (e.g., logos, hero images).
