Problem Breakdown

  • We need to implement a function race(funcs) that behaves like Promise.race(), but for callback-based asynchronous functions.
  • race(funcs) returns a new function that:
    1. Takes a single callback.
    2. Calls the callback as soon as any async function completes or fails.
    3. Ignores results from other async functions once the first one finishes.

Optimized Implementation

Step-by-Step Explanation

1. Preventing Multiple Calls

  • finished is initially false to track whether a result has been processed.
  • When the first async function completes:
    • callbackWrapper is invoked.
    • finished is set to true, preventing further executions.
    • callback(...args) is called with either the error or data.

2. Executing All Functions in Parallel

  • We iterate over funcs and call each function with callbackWrapper.
  • callbackWrapper ensures that only the first completion/error is handled.

Example Usage

Expected Output

  • Since asyncTask2 completes first (100ms), raceFunction invokes the callback.
  • asyncTask1 and asyncTask3 are ignored after asyncTask2 completes.

Time & Space Complexity

Operation Complexity
Iterating through funcs O(N)
Executing async functions O(1) per function
Overall Complexity O(N)
  • Time Complexity: O(N) (Each function is started, but only one finishes execution).
  • Space Complexity: O(1) (We use only a few variables).

Edge Cases Considered

  1. All functions fail:

    • The first error encountered will be returned.

  2. Empty function array:

    • No callback is ever invoked.
    • This scenario is undefined but should ideally be handled.

  3. Mixed success and failure:

    • The first async function to finish (success or failure) determines the result.
