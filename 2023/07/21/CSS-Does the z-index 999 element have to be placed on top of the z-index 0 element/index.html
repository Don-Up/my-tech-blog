Does the z-index 999 element have to be placed on top of the z-index 0 element

foreword

z-index is an important attribute in CSS that controls the stacking order of elements, which determines which element is displayed above in 3D space. Understanding the working mechanism of the z-index and the context that affects its action is critical to solving the problem of stacking and occlusion.

The basic mechanism of z-index

z-index only if the element is positioned ( position for relative , absolute , fixed or sticky ) is valid. It defines the hierarchical number in the stacking context of the element, the higher the number, the more forward the element.

Note, however, that z-index comparisons are only valid in the same stacking context. A stacked context is an independent hierarchical environment, and the z-index of internal elements is valid only with respect to elements within that context.

Impact of Stacking Context

if two elements are in different stacking contexts, even if the z-index of one element is 999 and the other element is 0, who ultimately overrides who depends on the hierarchical relationship of the stacking context to which they belong, rather than simply z-index values.

The New stacking context can be triggered by certain CSS properties, such position with and auto of z-index , opacity less than 1, transform wait.

Therefore, an element with a smaller z-index but in a higher stacking context may overwrite z-index larger elements.

Conclusion

z-index: 999 is not guaranteed to overwrite an element with z-index: 0 unless both are in the same stacking context. Understanding the generation and hierarchy of stacking contexts is key to the proper use of z-index.

Interview answer

z-index controls the hierarchy of elements in a stacked context, with higher numbers leading elements. But z-index comparisons are only valid in the same stacking context. If two elements are not in the same stacking context, even if the z-index of one is 999 and the other is 0, they may be overwritten or overwritten by each other. Thus z-index: 999 does not always cover z-index: 0.

Summary

the z-index takes effect depending not only on the numeric size, but also on the stacking context to which the element belongs. An in-depth understanding of the concept of stacking context helps to avoid stacking confusion and correctly control the order in which elements are displayed.
