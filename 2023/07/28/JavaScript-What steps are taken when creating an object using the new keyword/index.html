What steps are taken when creating an object using the new keyword

Foreword

in JavaScript, new keyword is the core mechanism for constructors to instantiate objects. Understanding new what is done behind the scenes helps to understand the object creation process and the formation of the prototype chain, so as to better grasp the object-oriented programming ideas. This article will be detailed analysis of the use new specific steps and principles when creating objects.

new keyword The process of creating an object

use new keyword when executing a constructor, the JavaScript engine performs roughly the following five steps:

  1. create a brand new empty object
    the new object will have a [[Prototype]] implicit properties (available in ES6 plus. __Proto__ access), initially pointing to the constructor’s prototype object.
  2. The constructor’s **this** point to this new object
    so that properties and methods inside the constructor can be passed throughthis to the new object.
  3. Execute the code in the constructor
    run the constructor body, assign properties to the new object or perform initialization logic.
  4. Judge constructor return value
    if the constructor explicitly returns an object, then new the result of the expression is the object; Otherwise, the new object just created is returned.
  5. Return to final object
    return the object obtained above to the caller.

Example Demo

if an object is returned in the constructor, new this is the object that is returned, not the new one.

Prototype chain formation

in the first step, the new object’s [[Prototype]] is pointed to by the constructor prototype property. In this way, the new object inherits the properties and methods on the constructor prototype, forming a prototype chain.

Details that need attention

  • when the constructor does not return an object, new automatically returns a new object.
  • If the constructor returns a value of a non-object type (such as a primitive type), the return value is ignored and the new object is still returned.
  • ES6class the instantiation process essentially follows this process.

Interview answer demonstration

problem: When using **new** what steps do you go through when you create an object with the keyword?

Example answer:

“ new when the operator executes, it first creates a new empty object, setting its prototype to point to the constructor’s prototype . Then put the constructor inside. this bind to the object and execute the constructor code. Then determine the return value of the constructor, if the return is an object, then return the object, otherwise return the newly created object. Finally return the result.”

summary

understanding new it helps to grasp the core principles of JavaScript Object creation, inheritance, and prototype chains, and improve object-oriented programming capabilities. It is the key bridge between functions and objects, and the foundation for understanding the implementation of ES6 class.
