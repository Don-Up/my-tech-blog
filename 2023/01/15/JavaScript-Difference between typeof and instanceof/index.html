Difference between typeof and instanceof

foreword

in JavaScript, typeof and instanceof it is two commonly used types of detection means, but their respective uses and working mechanisms are significantly different. Understanding the difference between the two is important for accurately determining variable types and avoiding type determination errors. This article will analyze in detail typeof and instanceof the difference and applicable scenario.

Working mechanism and characteristics of typeof

typeof is a unary operator that returns the type string of the operand. It is suitable for detecting basic data types and functions, but has limited ability to distinguish reference types.

Common return values include:

  • "undefined" : Variable is not defined
  • "boolean" : Boolean
  • "number" : Numbers
  • "string" : String
  • "symbol" : Symbol
  • "bigint": Large Integer
  • "function" : function
  • "object" : objects, arrays, null, and so on

typeof the advantage is that it is simple and fast, but the disadvantage is that it cannot distinguish between the specific types of objects, such as arrays and ordinary objects. "object" , and typeof null return "object" it is a problem left over from history.

The working mechanism and characteristics of instanceof

instanceof is a binary operator that determines whether an object is an instance of a constructor. It does this by checking for the existence of a constructor in the object’s prototype chain. prototype .

Example:

instanceof the advantage is that you can determine the specific type of complex objects. The disadvantage is that it relies on Constructors and prototype chains, and cross-environment (such as iframe) objects can lead to judgment failure because constructors are different in different environments.

Comparison of applicable scenarios

  • use typeofDetermine the existence or type of basic data types and functions.
  • Use instanceof determining whether an object is an instance of a class or constructor is suitable for detecting custom types or built-in objects.
  • For array judgment, it is recommended to use Array.isArray() instead instanceof to avoid cross-environmental issues.

Summary

typeof is a simple type of judgment, suitable for basic types. instanceof is based on the prototype chain instance judgment, suitable for complex objects. The two are used together to cover most types of testing needs.
