What are js macro tasks and micro tasks and what are their priorities

Foreword

in the JavaScript runtime, the scheduling of asynchronous tasks mainly depends on two types of queues: macro tasks and micro tasks. Understanding their definitions, differences, and prioritization is important to properly control the asynchronous execution process, avoid race conditions, and optimize performance. This article will introduce the concept, classification and execution order of macro tasks and micro tasks in detail.

Macro Tasks (Macrotask)

macro tasks are large, unitarily asynchronous tasks in the browser or environment and typically include:

  • timer tasks, such setTimeout , setInterval
  • user interaction events such as click, keyboard input
  • network request callback, such as XMLHttpRequest, Fetch callback
  • UI rendering task
  • I/O operations in Node.js and setImmediate

the macro task is the basic unit of execution in the event loop, and each loop takes a task from the macro task queue to execute.

Microtasks (microtasks)

microtasks are more fine-grained asynchronous tasks that are executed immediately after the current macro task finishes, ensuring completion before the browser renders or the event loop enters the next round. Common microtasks include:

  • promise’s callback function ( then, catch , finally )
  • MutationObserver callback
  • in Node.js process.nextTick

the microtask queue is emptied after each macro task is executed, and all microtasks are executed before the next macro task is executed.

Priority and Execution Order

in the event loop mechanism, each cycle follows the following sequence:

  1. execute a macro task
  2. execute all microtasks generated by the current macro task (until the microtask queue is empty)
  3. browser to render (if necessary)
  4. enter the next cycle of macro tasks

this means that microtasks have a higher priority than macro tasks, which are executed immediately after the macro task.

The Role of Microtasks

microtasks are guaranteed to execute some important tasks immediately after the end of the current execution context, such as the callback of Promise state changes, to ensure that data is updated in a timely manner and to avoid frequent UI redrawing.

The rational use of microtasks helps to write asynchronous code that responds efficiently.

Interview answer

A macro task is the basic unit of execution in an event loop and contains setTimeout , user events, network request callbacks, and other large asynchronous tasks.

Microtasks are more fine-grained asynchronous tasks, such as callbacks to promises and MutationObserver .

In the event loop, one macro task is executed each round, then all microtasks are executed, and finally rendering and the next round of macro tasks are performed. Therefore, micro-tasks have a higher priority than macro-tasks, which ensures that asynchronous code is executed in a more timely manner.

Summary

macro tasks and micro tasks are the two cores of JavaScript asynchronous mechanism. Macro task execution frequency is low, the scope is large; Micro task execution frequency, high priority. Mastering the difference between them and the order of execution helps to write more efficient and stable asynchronous code.
