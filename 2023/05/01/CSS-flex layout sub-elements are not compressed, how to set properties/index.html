flex layout sub-elements are not compressed, how to set properties

foreword

when using flex layout, the child element defaultsflex-shrinkproperties are compressed, which may cause the content to be squeezed and deformed. In order to avoid the child elements being compressed, the relevant attributes need to be set correctly to ensure that the child elements maintain at least their minimum size and ensure that the content is fully displayed.

How to avoid child elements being compressed

in the flex layout,flex-shrinkproperty controls the reduction ratio of child elements when there is insufficient spindle space. The default value is1, indicating that zooming out is allowed.

If you want child elements not to be compressed, you should set themflex-shrinkset0, indicating that zooming out is not allowed.
