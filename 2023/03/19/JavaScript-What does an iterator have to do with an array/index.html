Essential association between iterator and array

the relationship between them can be understood in several ways:

  1. arrays automatically implement the iterator protocol
    on each array instance. [Symbol.iterator] method, which internally maintains a “cursor” that returns each element in the array from beginning to end.
  2. The syntax of array for…of, deconstruction, etc. depends on the iterator protocol.
    When you use for...of arr or [...arr] the JavaScript engine automatically callsarr[Symbol.iterator]() to get the iterator object, and then call its next() methods.
  3. Arrays can interoperate with objects of other iterable protocols
    for example, Set, Map, string, etc. all implement the iterator interface, so you can use these objects with arrays, such Array.from(set) it is the iterator that reads the elements one by one and converts them into an array.
  4. Some methods of an array also return an iterator
    such arr.entries() , arr.keys() , arr.values() both return an iterator object instead of a normal array.

Review of the standard form of the iterator protocol

an iterator object must have a next() method, which returns a shape such {value: any, done: boolean} of the object.
