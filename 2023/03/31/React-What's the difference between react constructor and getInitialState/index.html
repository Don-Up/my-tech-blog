What’s the difference between react constructor and getInitialState

Foreword

in the development of React components, from ES5 createClass to the class component of ES6, the way to initialize the component state has also evolved. In the early React, developers used getInitialState method to set the initial state of the component, and in the later ES6 class component, constructor becomes the recommend way to initialize the state. Although both can do similar work, they are essentially different grammatical systems and life cycle stages.

This article will be in-depth analysis constructor and getInitialState the similarities and differences are expanded from the historical background, usage, life cycle, and code examples to help developers understand their roles and differences in React.

State initialization mode evolution in React

React.createClass and getInitialState

in React 0.x and earlier 15.x releases, React provides a method called createClass to define the component. It internally defines properties and methods in the form of object literals. Among them,getInitialState is the standard way to set the initial state of a component.

The essential difference between the two

1. Grammatical mechanism is different

getInitialState is the internal API of React, only in createClassEffective in the mode; And constructor it is the ES6 constructor of native JavaScript and is a common language mechanism. React only uses it to initialize the component state.

2. Life cycle location is different

in createClass React is automatically called when the component is created. getInitialState and assigns the return value to the component’s state property. In the class component, constructor is called by the JavaScript engine before the component is instantiated to initialize instance properties (e. G. state , binding methods, etc.).

3. The treatment of this is different.

In getInitialState React automatically binds this is a component instance; And in constructor developers need to manually call super(props) in order to accessthis.props .

4. Is it still available

getInitialState it is no longer recommend to use. React has removed its related support from the document and may only exist in old projects. Now you recommend use class components or function components useState hook for state management.

Summary

from getInitialState to constructor , is React’s transition from the early encapsulation API to the modern standard JavaScript. With the introduction of Hooks and the widespread use of function components in React, the initialization method of component state has gradually migrated from class components to function components.

Although it is now almost never used again getInitialState but understand it and constructor the difference helps us to grasp the historical evolution, grammatical changes, and underlying operating mechanisms of React. This knowledge is still valuable when maintaining old code, interview answers, or writing custom abstract components.
