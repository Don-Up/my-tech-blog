What are the ways to judge arrays

Foreword

in JavaScript, determining whether a variable is an array is a common requirement in development. Since arrays are essentially objects, use the simple typeof there is no distinction between arrays and ordinary objects, so there are many ways to judge arrays. This article will systematically introduce several commonly used array judgment methods, analyze their advantages and disadvantages and applicable scenarios.

The main array judgment method

1. Array.isArray()

this is the standard method introduced by ECMAScript 5 to accurately determine whether a variable is an array. It returns a Boolean value with clear semantics and good compatibility, which is the recommend way to use it.
