react diff algorithm

Foreword

react’s efficient update performance is inseparable from its core algorithm-Diff algorithm. The Diff algorithm is responsible for comparing the differences between the old and new Virtual DOM trees, calculating the smallest set of changes, and finally applying these changes to the real DOM in batches to achieve high-performance UI updates.

This article will analyze in detail the principles, core strategies, optimization points, and implementation details of the React Diff algorithm to help readers deeply understand how React efficiently implements differentiated updates of Virtual DOM, thereby improving application performance.

Basic principle of React Diff algorithm

during the update process, React needs to compare the new Virtual DOM tree with the old Virtual DOM tree to calculate the difference. This process is called Diff.

However, a direct comparison of all the nodes of the two trees, the time complexity is O(n), which is extremely costly. React uses a series of assumptions and optimization strategies to control the Diff process within the time complexity of O(n).

The core assumptions and optimization strategies of React Diff.

1. Same layer comparison

React only compares nodes at the same level, not across levels. If the child nodes are different, Diff is recursively called on the child nodes.

2. Different types of nodes will be replaced as a whole.

If the type of two nodes ( type ) Different, React will think that the entire node tree needs to be replaced instead of trying to compare in depth.

3. Nodes of the same type perform attribute updates and child nodes Diff.

For nodes of the same type, React reuses the node, updates its properties, and Diff the child nodes further.

4. Use key to optimize the list Diff.

When the child node is a list, React uses key to identify unique nodes for efficient insertion, deletion, and movement identification.

Detailed explanation of Diff process

the main process of React Diff can be split into the following steps:

  • determine the node type compares whether the old and new node types are the same.

  • Update Properties : Compares and updates differential properties for nodes of the same type.

  • Recursively Diff child nodes :

  • if it is a normal node, compare the child nodes in the corresponding position in order.

  • For the list, combined with the key to do complex move, insert, delete processing.

  • Remove redundant nodes deletes nodes in the old tree that do not exist in the new tree.

List Diff optimization details

for lists without keys, React compares them one by one in index order, but this results in a large number of delete and reinsert operations during movement, resulting in poor performance.

If there is a list of keys, React will first build a mapping table of keys to indexes of new and old nodes, and quickly locate nodes through hash lookup to achieve:

  • Reuse nodes (reduced creation and destruction)
  • efficient mobile nodes (reduce DOM operations by computing the longest incremental subsequence)

Diff optimization in React Fiber

the Fiber architecture enables a more efficient and schedulable Diff by splitting the coordination process into incremental interruptible tasks.

In addition, Fiber is more complicated for Diff of the list, combining key and priority, supporting interrupt and recovery, and avoiding blocking the main thread for a long time.

Interview answer example

question: Please briefly describe the principle and optimization strategy of The React Diff algorithm.

Example answer:

The React Diff algorithm calculates the minimum difference between the old and new Virtual DOM trees to update the real DOM. In order to reduce the time complexity, React makes three core assumptions: only compare nodes of the same layer, replace nodes of different types as a whole, update attributes of nodes of the same type and recursively Diff child nodes.

For lists, React uses keys to uniquely identify nodes, optimize insertion, deletion, and movement, and improve performance. The Fiber architecture further splits the Diff into interruptible tasks, improving scheduling flexibility and responsiveness.

Summary

React Diff algorithm is the key to achieve high-performance UI update, combined with reasonable assumptions and strategies to control the complexity within an acceptable range. By using key to optimize the scheduling capabilities of list Diff and Fiber, React can achieve smooth and efficient interface rendering.

Understanding The React Diff algorithm not only helps optimize component design, but also helps developers better debug and improve application performance.
