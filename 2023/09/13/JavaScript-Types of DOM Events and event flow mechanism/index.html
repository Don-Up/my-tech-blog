Types of DOM Events and event flow mechanism

Foreword

DOM Event mechanism is the basis of front-end development, and mastering the working principle, event model and common operation of events is the key to writing efficient interactive code. This article will systematically explain the type of DOM Events, event flow, event binding and removal, event delegation and other related knowledge.

Basic concepts of DOM Events

DOM events are response signals for user or browser actions, such as click, enter, load, etc. After the event is triggered, the browser executes the corresponding event handler function according to the event flow.

Event Type

  • mouse Events click, dblclick, mousedown, mouseup, mousemove, etc.
  • Keyboard Events : keydown, keyup, keypress (deprecated).
  • Form Events : submit, change, input, focus, blur, etc.
  • UI events : resize, scroll, load, etc.

Event flow mechanism

the event flow is divided into three phases:

  1. capture phase the event propagates from the document root node to the event target node.
  2. Target Phase : The event reaches the target node.
  3. Bubbling phaseThe event backpropagates from the target node to the document root node.

By default, event listeners fire during the bubbling phase. You can pass the third parameter ( useCapture ) Decide on the listening phase.

Event Binding and Removal

  • use addEventListener(type, listener, useCapture) add event listeners.
  • Use removeEventListener to remove the event listener, ensure that the same function reference and parameters are passed in.
  • Traditional onclick property bindings such as can bind only one event handler.

Event Delegation

event delegation is to bind the event listener to the parent element, listen to the events of the child element through the event bubbling mechanism, improve performance and dynamic element support.

event Objects and Blocking Default Behavior

the event handler function receives the Event object, which contains information such as the event type, target element, coordinates, and so on.

By calling event.preventDefault() block default behavior, calling event.stopPropagation()Preventing event bubbling.

Interview answer demonstration

q: “Please briefly describe the types of DOM events and the event flow mechanism.”

“There are many types of DOM events, including mouse events, keyboard events, form events, and UI events. The event flow is divided into a capture phase, a target phase, and a bubbling phase. Events are captured from the document root node to the target element, and then bubbled back to the root node.

You can choose which phase to trigger when listening for events. Event delegates use event bubbling to bind listeners to parent elements for efficient management of large number of sub-element events.”

summary

understanding the types of DOM Events and event flows helps to bind events correctly and optimize performance. Mastering event delegation and Event object manipulation is the basis for writing robust interaction code.
