What is a pseudo array and what is a class array

foreword

when learning JavaScript, we often encounter the term “pseudo-array” or “class array”, especially when dealing with DOM sets and function parameters. Although these two terms are often used interchangeably, their definitions, usage scenarios, and characteristics are not exactly the same. Understanding these two concepts helps us avoid misuse or error reporting when manipulating data structures.

Definition and Characteristics of Class Array

an Array-like Object is an Object that has the following characteristics:

  • key names that have numeric indexes (such "0" , "1" )
  • have length property
  • prototype methods that do not have arrays (e. G. forEach , map etc.)

What is a pseudo array?

“Pseudo-array” is the unofficial name for the class array, which is mainly used to describe objects that behave like arrays, but are not arrays in nature. For example:

  • arguments object
  • DOM method returned NodeList
  • string (partial behavior)
  • document.forms , HTMLCollection

although the terminology is different, in essence “pseudo-array” is a popular term for “array-like. Strictly speaking, all pseudo-arrays are class arrays, but not all class arrays are called pseudo-arrays.

Differences between pseudo-arrays and arrays

  • type is different: The array is Array instance of, the class array is not
  • method support is different: arrays have prototype methods (e. G. map , reduce ), class arrays usually do not have
  • scalability is different: arrays can be expanded dynamically through methods, and class arrays have limited behavior.
