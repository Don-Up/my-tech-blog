What is the principle of implementing lazy loading with react lazy import

Foreword

in modern front-end development, with the increasing application volume, how to optimize the first screen loading time and improve the user experience has become an important issue. React provides a built-in React.lazy API, with dynamic import() implement lazy loading of components. By loading on demand, the initial packaging volume can be significantly reduced, achieving faster loading speed and better performance.

This article will analyze React from the principle level. lazy how to achieve lazy loading, including its internal mechanism, coordination Suspense workflow, as well as practical application should pay attention to the key points, to help developers in-depth understanding and correct use of this feature.

the core implementation principle of React.lazy

1. Dynamic import()

React.lazy the lazy loading ability depends on the JavaScript dynamic import()Syntax. Dynamic import returns a Promise that represents the asynchronous loading of the module.

When React renders a lazy load component, the passed-in function is executed ( () => import('./HeavyComponent') ), triggering the module asynchronous request.

2. The component state is “asynchronous”

React.lazy returns a special React component, which initiates a module load request during the first rendering and returns a Promise. React will “suspend” the rendering process of the component until the Promise is resolved (module loading is complete).

3. React Suspense

Suspense the component is used to wrap lazy loading components and provides a placeholder UI(fallback) during loading. When the Promise of the lazy loading component is not completed, React renders fallback; When the loading is completed, the real component is rendered.

React coordinates asynchronous loading and rendering to make the asynchronous component loading experience natural and smooth.

III. React.lazy Internal Workflow (Simplified Version)

stage description
when the component is rendering call dynamic import, return Promise
React Detection Promise Status If an uncompleted Promise is found, fallback of Suspense is triggered.
Promise to resolve the module is loaded successfully, React obtains the default export of the component.
Component re-render render the React component corresponding to the lazy loading module

React internally tracks the Promise and its status, and suspends the rendering process until the module is loaded to ensure the correct rendering of asynchronous components.

React.lazy’s Limitations and Points for Attention

  • can only be used for default export : The dynamic import module requires the default export component and cannot be used for named export, otherwise an error will be reported.
  • Use with Suspense : Suspense is responsible for handling the loading state, otherwise an exception will be thrown when rendering.
  • Server-side rendering (SSR) is not supported : React.lazy is only suitable for clients, SSR requires other schemes.
  • Code splitting depends on packaging tool support : Packaging tools such as webpack need to support dynamic import to generate on-demand split code.

Summary

React.lazy uses the JavaScript dynamic import feature and React suspend to load components asynchronously on demand. Its principle is to return a Promise through the dynamic loading module, React suspends the component during rendering, and waits for the Promise to resolve before continuing rendering. This ensures both the code segmentation effect and the loading experience. Reasonable use of React.lazy can significantly improve application performance, especially for SPA with large volume and many pages.

Interview answer

question: What is the principle of lazy loading in React.lazy import?

Answer:

React.lazy is a lazy loading based on JavaScript dynamic import implementation. Dynamic import returns a Promise that represents the asynchronous loading of the module. React.lazy receives a function that, when executed, triggers the module to load and returns a Promise. React tracks this Promise through an internal mechanism and suspends the current component rendering when the load is not completed. You need to cooperate with the suspend component to display the loading status. After the Promise is resolved, React obtains the default export component of the module and re-renders it to realize asynchronous loading. This enables on-demand loading, reduces the initial package size, and improves performance. However, React.lazy only supports the default export component and must be used with suspend.
