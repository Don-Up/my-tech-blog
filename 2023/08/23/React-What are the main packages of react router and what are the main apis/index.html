What are the main packages of react router and what are the main apis

Foreword

React Router is the most important routing solution in the React ecosystem, helping developers easily manage routing and navigation in single-page applications (SPA). With the iteration of The React Router version, its functions and module structure are gradually improved and subdivided, supporting multiple routing modes and complex routing scenarios.

This article will introduce the main package components of React Router and its core API in detail, and analyze their functions and usage in combination with code examples to help you better understand and master the usage of React Router.

React Router main package introduction

since the v6 version of React Router, the overall structure has changed greatly, with finer subpackages and more focused functions. The following are the main packages and their functions:

  • react-router
    this is the core package of React Router, which provides route matching algorithm and routing context management. The underlying routing mechanism is implemented here. Mainly responsible for routing state management, path matching, navigation action, etc. It does not itself contain any React components.
  • react-router-dom
    this package is encapsulated for the browser environment and provides a number of React components for DOM-based routing. Common components such <BrowserRouter>, <Routes>, <Route>,<Link>, <Navigate>everything is in this package. This package is primarily used when developing browser-side spas.
  • react-router-native
    for the routing package of React Native Applications, Native routing support is provided. The components and API design are similar to react-router-dom, but adapt to the Native mobile environment.

React Router core API details

the following focuses on the most commonly used in browser-side development. react-router-dom the main APIs and components.

1. <BrowserRouter>

It is used to wrap applications and realize routing management based on HTML5 History API. It listens to browser address changes and coordinates route rendering.

2. <Routes>And <Route>

<Routes>is a routing container used to wrap a group <Route>. <Route>Used to declare the correspondence between a path and a component.

3. <Link>

Used to declare navigation links, instead of the native <a>label, to achieve no refresh jump.

4. <Navigate>

Programmatic redirection component, alternative history.push realize route jump.

5. useNavigate

the Hook of the navigation jump in the functional component, which returns a jump function.

6. useParams

gets the Hook for route parameters, for routes that declare a dynamic path.

7. useLocation

obtain the location information object of the current route, including the pathname, search, and hash.

8. useMatch

used to match a specific path, returns a matching object, or null.

summary

The React Router is split react-router (Core mechanism), react-router-dom (Browser implementation) and react-router-native (Native end implementation) three packages, to achieve a highly flexible routing management system. Its core APIs and components such <BrowserRouter>, <Routes>, <Route>, <Link>as well as many hooks, greatly simplifying the development complexity of SPA routing.

Mastering these core APIs can help developers design routing structures more efficiently, implement page navigation, parameter transfer, and route control, and improve user experience and code maintainability.

Interview answer

question: What are the main packages of React Router and what is the core API?

Answer: React Router is mainly divided into three packages: react-router is the core routing logic package, does not contain UI components; react-router-dom是针对浏览器环境的路由组件包，包含<BrowserRouter>、<Routes>、<Route>、<Link>等组件以及 Hook；react-router-native是针对 React Native 的路由包。

核心 API 包括：

  • <BrowserRouter>：应用根路由容器，基于 History API。
  • <Routes>和<Route>：声明路由匹配规则和渲染组件。
  • <Link>：无刷新导航链接。
  • <Navigate>：编程式重定向。
  • useNavigate、useParams、useLocationSuch as a Hook, which is used to jump routes and obtain routing information.

Through these APIs, you can implement flexible and declarative Client routing management to meet the needs of single-page applications.
