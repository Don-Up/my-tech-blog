What are the common attributes in flex layout and what are their functions respectively

foreword

Flexbox (flexible box layout) is a powerful tool for solving one-dimensional layout problems in modern CSS. It simplifies complex layout requirements, especially in responsive design. Understanding the commonly used flex properties and their functions is the basis for flexible layout construction.

Common flex container properties

  1. display: flex or inline-flex
    define the flexible box container and activate the Flexbox layout mode.
  2. flex-direction
    sets the spindle direction. Common values are row (Default, left to right), row-reverse , column (From top to bottom), column-reverse .
  3. justify-content
    defines the alignment of child elements on the major axis (horizontal or vertical, depending on the orientation), such flex-start , center ,space-between , space-around wait.
  4. align-items
    defines the alignment of all child elements on the cross axis, such stretch (Default, stretch fill), center , flex-start , flex-end .
  5. flex-wrap
    control whether to wrap the line, the default is not to wrap the line. nowrap , wrap , wrap-reverse .
  6. align-content
    when there are multiple rows, define the alignment of multiple rows on the cross axis, similar justify-content but for multiple lines.

Common flex child element attributes

  1. flex-grow
    defines the magnification ratio of the child element in the remaining space. The default value is 0.
  2. flex-shrink
    defines the reduction ratio of the child element when there is insufficient space, the default is 1.
  3. flex-basis
    defines the initial size of the child element on the main axis, the default auto .
  4. flex
    yes flex-grow , flex-shrink and flex-basis the abbreviation of, commonly used writing such flex: 1 .
  5. align-self
    allows a single child element to override the container’s align-items property, independently sets its own alignment on the cross axis.

Interview answer

Flexbox Common container properties are display: flex activate the layout, flex-direction set the spindle direction, justify-content control spindle alignment,align-items controls cross-axis alignment, flex-wrap control newline, align-content controls multi-line alignment. Common attributes of child elements are flex-grow define the magnification ratio, flex-shrink define the reduction ratio, flex-basis set the initial size, flex is shorthand for the three, align-self for individual alignment.

Summary

Flexbox provides rich properties to control layout orientation, alignment, and scaling behavior, helping developers easily achieve flexible and responsive design. Mastering these attributes can significantly improve the efficiency and quality of the front-end layout.
