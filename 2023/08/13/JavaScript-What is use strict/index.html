What is use strict

Foreword

JavaScript is a language with a high degree of design freedom, and this flexibility brings the convenience of rapid development and introduces many potential problems. To improve the robustness and security of the code, ECMAScript 5 introduces “strict mode”-I .e. "use strict" . This is a way to run JavaScript code with stricter syntax rules, which can help developers avoid common pitfalls and find problems in advance. This article will be in-depth analysis use strict the role, characteristics and mode of use.

Text

what is “use strict”

"use strict" is a kind strict mode enabled declaration string , the scope of action can be entire script or single function . Once enabled, the JavaScript engine will execute code in a stricter and safer way, throwing some problems that will not be reported in non-strict mode.

II. Role and limitations of the strict model

here are some of the key changes and enhanced behaviors in strict mode:

  1. prohibit the use of undeclared variables

in non-strict mode, writea = 10 A global variable is implicitly created. In strict mode, you must first pass var / let / const declare the variable, otherwise throw ReferenceError .

  1. Disable deleting a variable or function

such delete a , delete functionName an error will be reported in strict mode.

  1. Disable duplicate declaration of parameter names

such function test(a, a) is legal non-strict code, but is a syntax error in strict mode.

  1. octal syntax prohibited

Such var num = 010 (Representing decimal 8) will report an error in strict mode.

such package , interface future reserved words such as cannot be used as variable names.

  1. Restrict function Internal use arguments.callee and arguments.caller

these writing methods are disabled in strict mode to help optimize and improve code maintainability.

summary

strict mode is an important feature introduced by JavaScript to improve the robustness of the language. By "use strict" , we can expose potential runtime problems in advance and force developers to follow more standardized coding practices. Although modern modular systems (such as ES modules) enable strict mode by default, a deep understanding of its role is still an important part of mastering the basics of JavaScript.
