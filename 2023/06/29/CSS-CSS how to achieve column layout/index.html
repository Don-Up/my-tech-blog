CSS how to achieve column layout

foreword

column layout is a common way of typesetting, often used in newspapers, magazines and Web design, the content is divided into multiple columns, so that reading more clear and orderly. CSS provides a variety of column layout technology to meet different needs of visual and functional effects.

The main way for CSS to achieve column splitting.

  1. CSS Multi-column Layout
    this is a collection of attributes introduced by CSS3 specifically for multi-column typesetting, mainly including:
  • column-count : Specify the number of columns
  • column-width : Specify the width of each column
  • column-gap : Set column spacing
  • column-rule : defining inter-Column dividers

for example:

the contents of the container are automatically divided into three columns with spacing and separation lines between the columns.

The multi-column layout is suitable for text streaming, and the browser will automatically distribute the content, so that the height between the columns is basically balanced.

  1. Flexbox layout
    use the elastic box layout by setting the container display: flex , and give the child elements a fixed width or equal width, can also achieve a multi-column effect, but the content will not automatically split.
  2. Grid Layout
    CSS Grid can also implement complex multi-column structure by defining columns and rows, which is suitable for the layout of fixed partitions.
  3. Floating Layout
    traditionally, by setting the element float: left and set the width to achieve multi-column arrangement. The disadvantage is that you need to clear the float, and does not support automatic content column.

Application recommendations

the CSS multi-column layout is suitable for scenes with a lot of text content and automatic paging is required. Flex and Grid are suitable for controlling unambiguous block distribution. Floating layouts were gradually replaced by modern layouts.

Interview answer

the most direct way to implement column layout in CSS is to use multi-column layout properties, such column-count and column-gap , the browser will automatically divide the content into the specified number of bars and balance the height. In addition, you can also use Flexbox or Grid to achieve column, but they are more suitable for fixed area layout, floating layout is the traditional scheme, good compatibility but complex to use.

Summary

column layout is an important means of typesetting, and CSS multi-column layout provides a simple and efficient implementation. Understanding the application scenarios of different layout techniques helps to choose the most appropriate column scheme according to the needs.
